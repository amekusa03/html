1.vercel site

Site map creation

sitemap.xmlCreate and place it in the root folder.

sitemap.xmlis an XML file that describes the pages to be searched, making it easier for search engines to recognize the pages on your site.

There are various sitemap generators available online that can be easily generated by simply entering a URL.

If you ask Gemini, it will analyze your site structure and automatically generate the optimal sitemap.

Site map registration

In Google Search Console to propertieshttps://amekusa.vercel.app/ set

  • Indexing → Sitemap
  • Adding a new sitemap:sitemap.xml Enter and send

Initially, I got a "Failed to retrieve" error on Search Console. Although it can be confirmed from the browser, crawler tools such as Gemini and Copilot also determined that the file does not exist.

The cause was a bot block caused by Vercel's security settings. On the Vercel management screen, configure the following settings. Enabled for Standard Protection from Disabled It was resolved by changing (Save) to . However, this setting may reduce security, so Enabled for Standard Protection We recommend reverting to .

As a result, Google Search Console now loads sitemap.xml successfully.

This makes it easier for Google to crawl your site's pages, increasing your chances of appearing in search results.

2.Google Blogger sitemap settings

Google Blogger automatically generates sitemap.xml.

You can access the sitemap by adding the blog URL + /sitemap.xml to Google Search Console.

Example: https://amekusa03.blogspot.com/sitemap.xml

Example sitemap.xml

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://amekusa.vercel.app/</loc>
    <lastmod>2024-06-01</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>

explanation

  • XML declaration: Specify the XML version and encoding.
  • xmlns attribute: Specifies the schema for the sitemap protocol.
  • loc: Specify the absolute URL of the page.
  • lastmod: Last updated date. This will help search engines decide whether to re-crawl.
