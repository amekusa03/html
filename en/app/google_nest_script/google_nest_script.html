About this Project

Introducing an example of customization using Google Nest Hub's script function. Create conditions and actions with scripts to make Google Nest Hub function.

Video

Implementation

This time, I created a script to play a specific video on Google Nest Hub when I asked ``Introduce the Nest Hub Script.'' Similar settings can be made using the Google Nest Hub GUI, but I think it will be easier for engineers to understand. 


metadata:
  name: Nest Hub Script Introduction
  description: Self-introduction
automations:
  - starters:
      - type: assistant.event.OkGoogle
        eventData: query
        is: "Introducing nest hub scripts"
    condition:
      type: device.state.Online
      device: Nest Hub - Living Room
      state: online
      is: true
    actions:
      - type: assistant.command.OkGoogle
        devices:
          - Nest Hub - Living Room
        okGoogle: Play video "Nest Hub Script Introduction"

Explanation

  • metadata: Define basic information for the script. name is the name of the script and description is the description of the script.
  • automations: This section defines automation rules.
  • starters: Define the conditions to start the automation. Here, it's triggered when the user says "Introduce NestHub Script."
  • condition: Defines conditions that must be met before an action is performed. Here, we assume that the Nest Hub is online.
  • actions: Define the action to be performed when the condition is met. Here, Google Nest I am setting an action to play a specific video on the Hub.

OS / Environment

  • Google Home Script Editor

Key Features

  • Flexible scheduling: The GUI allows difficult condition settings.
  • Device broadcast cooperation: Directly control Nest Hub functions and realize video playback.

Known Issues
