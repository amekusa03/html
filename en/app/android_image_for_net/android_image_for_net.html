Android Image for net

Android image processing app that supports EXIF ​​information deletion and watermark addition

About this Project

Android Image for net is an Android app that allows you to easily protect privacy (remove EXIF ​​information) and add watermarks before posting images to the Internet. Compatible with Android 6.0 (API 23) or higher.

Helps protect privacy and identify original content when posting images online.

Video

Key Features

  • Delete EXIF ​​information: Permanently removes metadata such as GPS location information, shooting date and time, and camera model.
  • real time watermark: You can set free text and place it at the top left/top right/bottom left/bottom right.
  • Customizable: Adjust font color, size, and opacity, and preview instantly.
  • Share function: You can share the edited image as is to other apps.
  • simple operation: Simply select an image from the gallery, process it with an intuitive UI, and save it.

Technology Stack

  • Kotlin
  • Jetpack Compose / Material Design 3
  • MVVM (ViewModel + State)
  • androidx.exifinterface
  • Bitmap API

Setup

Open your project in Android Studio, perform a Gradle sync, then run it on your device or emulator.
