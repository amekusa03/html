About this Project

This is a project to reuse old Windows PCs as active terminals by replacing them with Ubuntu, a lightweight Linux distribution. Reduce disposal costs and achieve green computing.

Video

OS / Environment

  • Ubuntu 22.04 LTS
  • Lightweight Desktop Environment
  • Linux Kernel

Key Features

  • Faster: Significantly reduces system resource consumption compared to Windows.
  • Security: From an OS that is no longer supported to an environment where you can receive the latest security updates.
  • Software compatibility: Set up apps needed for web browsing and document creation.
