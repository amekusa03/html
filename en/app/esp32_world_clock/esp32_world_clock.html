ESP32 world Clock for Wokwi

Simulating a world clock with ESP32

About this Project

This is a Wokwi project. A world clock that displays time and date on an LCD1602 display. Time is synchronized via NTP.

Video

Development Environment

  • ESP32
  • C
  • Wokwi

Key Features

  • NTP time synchronization: Get accurate time via internet and sync automatically.
  • LCD1602 display: Efficiently layout date and time within a limited display area.
  • Wokwi simulation: The development environment can be completed on a browser, making it possible to check operation without any hardware.
