ESP32 Racing Game for Wokwi

Racing game using ESP32

About this Project

This is a racing game using ESP32. It is assumed that it will run on Wokwi.

Circuit Demo

Video

Development Environment

  • ESP32
  • C (Arduino Core)
  • Wokwi

Key Features

  • ESP32 control: Controls the ESP32 hardware and realizes racing game operations.
  • Wokwi simulation: Simulate games and improve development efficiency with Wokwi.
  • User action: Control the progress of the game according to user input.
