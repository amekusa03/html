Android Web Launcher

"Rancha" that behaves like an Android app

About this Project

This is a ``Rancha'' app that makes a specific web page behave like an independent Android app. Users can manage up to 5 presets (drawer display) and unlimited home screen shortcuts. This allows you to easily access certain web pages.
The name "Rancha" comes from the fact that this rancher was born in Shizuoka, which is famous for its tea production.

Video

Development Environment

  • Kotlin
  • Android SDK

Key Features

  • Displaying a web page as a separate app: Display a specific web page as if it were an independent Android app.
  • User friendly: Easy to operate with intuitive UI.

Out of Scope

  • The function to display an arbitrary name on the drawer is currently not implemented.
  • We have confirmed that there is a behavior that depends on the launcher app, and that it can be changed with Nova Launcher, but cannot be changed with AQUOS HOME.
