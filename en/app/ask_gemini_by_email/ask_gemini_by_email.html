Email Gemini

Guide to using Google Gemini in an email environment


This time we have created materials for amateurs.

Click here for materials for amateurs

About this Project

I have an email environment, but when I can't use a browser or smartphone, If you send an email to yourself, Gemini's response will be emailed to you.

Video

Development Environment

  • Google Apps Script
  • GmailApp
  • Google Cloud Platform
  • UrlFetchApp

How to Use

  1. Create a project on Google Cloud Platform and enable Gemini API.
  2. Obtain the API key and set it in the Google Apps Script project.
  3. Set up an email reception trigger with Google Apps Script and create a script that calls the Gemini API when an email with a specific subject or content is received.
  4. Implement the script to process the response from the Gemini API and send the appropriate reply email.
  5. Send a test email to confirm that the system is working properly.

Key Features

  • lightweight: Significantly reduces system resource consumption.
  • Email-based interface: Even in environments where you cannot use a browser or smartphone, you can interact with Gemini via email.
  • Security: Leverage Google Apps Script's security model to securely manage API keys and protect communications.
