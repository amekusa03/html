ESP32-C3 Data Logger SHT31 LittleFS

Temperature and humidity data logger for mountain fields (Hata logger)

Specifications for a self-contained data logger that automatically records environmental data over a long period of time in mountain fields (without power or internet) and collects the data using a smartphone on-site.

1. System overview

  • Usage: Fixed-point observation of temperature and humidity in mountain fields
  • Measurement interval: Every hour (power saving operation using deep sleep)
  • Data storage: Save in CSV format to the internal flash memory (LittleFS) of ESP32-C3
  • Data collection: Download from your smartphone browser via Wi-Fi (access point mode) on-site.
  • power supply: Powered by installed solar charge controller (USB 5V)

Video

2. Hardware configuration (parts list)

① Microcomputer board

  • Model number: ESP32-C3 development board (recommended: Seeed Studio XIAO ESP32C3 or other power-saving design)
  • Features: Low power consumption (approximately 50μA or less during sleep), Wi-Fi installed, small size

② Temperature and humidity sensor

  • Model number: GY-SHT31-D (module with Sensirion SHT31)
  • Features: High accuracy (temperature ±0.2℃ / humidity ±2%), high durability against condensation

③ Other parts

  • Data collection switch: Tact switch x 1 (for switching modes at hand)
  • case: Waterproof/dustproof plastic box (manufactured by Takachi Electric Industry, etc.)
  • Wiring material: 4-core cable, solder, and heat shrink tubing for sensor extension
  • Rust/waterproofing measures: Self-adhesive tape, putty (or silicone sealant), moisture-proof coating agent (Hayacoat)

4. Operation specifications (software processing flow)

[Normal: Logger mode]

  1. Wake: Built-in timer automatically starts every hour.
  2. Initialization: Initializing LittleFS and SHT31 sensors.
  3. Data measurement: Measures temperature and humidity.
  4. Data storage: log.csv Add data to the end of (format: serial number, temperature, humidity).
  5. Bedtime: Set a timer for 1 hour (3,600 seconds) and immediately go into deep sleep.

[When collecting: Wi-Fi mode]

  1. Launch trigger: While pressing the switch connected to GPIO 9, press the "EN (reset) button" on the main unit.
  2. Mode branch: Immediately after startup, it detects that GPIO 9 is LOW and starts up as a Wi-Fi base unit.
  3. Wi-Fi activation: SSID: Hata_Logger / PASS: 12345678 Expand the access point.
  4. Start web server: http://192.168.4.1 Start up a web server.
  5. Smartphone connection/collection:
    • Smartphone Wi-Fi Hata_Logger Connect to.
    • in browser http://192.168.4.1 Access.
    • Execute "CSV download" and "data deletion" from the buttons on the screen.
  6. How to exit: After collection is complete, press the EN button again without pressing the switch (return to normal mode).

5. Special notes/long-term operational measures

  • Time accuracy: Since an external RTC (clock module) is omitted, the system is operated on the assumption that there will be a cumulative error (deviation) of about one hour per week due to the temperature characteristics of the built-in timer (count back against the actual time at the time of collection).
  • Sensor protection: When soldering, protect the sensor with masking tape to prevent solder smoke (flux gas) from entering the hole in the center of the sensor.
  • Moisture proof/insect proof: To prevent condensation, apply a moisture-proofing agent such as Hayacoat to the board (other than the sensor). Completely fill the hole for the wire that runs from the case to the sensor with putty to prevent insects from entering.
  • Rust prevention: The USB connection between the solar controller and ESP32-C3 is sealed with self-adhesive tape to prevent corrosion due to moisture.
