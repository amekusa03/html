We created and simulated a simple program using the software PLC development environment "CODESYS" that complies with the international standard IEC 61131-3.

Definition: Soft PLC

Software PLC: A control system in which the control logic is separated from dedicated hardware and can be executed on general-purpose hardware or a virtualized environment (hypervisor, etc.).

On the other hand, Mitsubishi Electric Q series and Omron NJ have unique specifications for both hardware and software.hardware plcIt is called.

What is CODESYS?

This software is compliant with IEC 61131-3 and allows you to integrate and develop PLC/Motion/HMI. It has been used by over 400 OEM customers and thousands of end users around the world.

  • Integrated development environment: PLC, Motion, and HMI settings can be performed all-in-one.
  • Asset reuse: Because it complies with international standards, the portability of software assets is high.
  • Free use: The development environment is available free of charge to users all over the world.
