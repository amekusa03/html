SekkaTi

memo tool

About this Project

A memo pad for impatient people. Just take it out, write on it, and put it away.

  • Instant launch with hotkey: Call anytime from OS shortcut settings.
  • Auto save: When it loses focus, it automatically saves the contents and exits.
  • No file management required: It is automatically named using the timestamp, so there is no need to think of a name.
  • Timeline reference: Quickly view past memos by "today", "yesterday", etc.
  • Resident type: It waits in the background to prevent double activation.
