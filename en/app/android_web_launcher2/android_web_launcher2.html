Android Web Launcher 2

“Awacha” site launcher with hierarchical management and “hot water cup” design

About this Project

"Awacha" is a launcher app that allows you to quickly open a specific website from the Android home screen. The previous "5 limit" has been significantly expanded, and a folder structure with up to 4 layers (16 slots of 4 x 4 per screen) has been introduced. You can now organize and manage a large number of shortcuts. This allows you to easily access certain web pages.
The name "Awacha" comes from the fact that this launcher was born in Shizuoka, a region famous for producing tea.

Video

Development Environment

  • Kotlin / Jetpack Compose
  • Room (data persistence)
  • ShortcutManager API
  • Chrome Custom Tabs

Key Features

  • Hierarchical management: Adopts a folder format that allows nesting up to 4 levels.
  • Hot water cup design: Adopts color-coded cylindrical icons for each slot. Customizable through an intuitive color panel.
  • Favicon automatic acquisition: Automatically retrieves the site icon from the URL and places it in the center of the teacup.
  • Dedicated mode: After launching the URL, the launcher itself will automatically finish and will not remain in the background.
  • Breadcrumbs: Even if the hierarchy becomes deep, the icon display and text navigation make it easy to understand your current location, and it is easy to jump to higher levels.
  • Dynamic shortcuts: Shortcuts created on the Android home screen will be automatically synced when edited within the app.

Known Issues / Out of Scope

  • The behavior of updating and displaying home screen shortcuts depends on the specifications of the launcher app (home app) you are using. Nova Dynamic updates are reflected immediately in Launcher, etc., but some pre-installed launchers may have restrictions.
