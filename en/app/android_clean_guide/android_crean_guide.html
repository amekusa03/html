How to organize Android unnecessary apps (script edition)

Rather than manually entering ADB commands one by one, we will explain how to use a PowerShell script to organize while leaving a deletion log.

About this guide

Many sites introduce how to delete preinstalled Android apps using ADB. This guide does not explain basic ADB operations."PowerShell script that organizes deleted apps while recording them in a text file"I will focus on how to use it.

Using scripts has the following advantages:

  • A record of what was deleted remains
  • You can delete multiple apps in succession
  • You can also perform restore operations while viewing the logs.

Prerequisites

Before proceeding with this guide, you must have:

  • to PCADB（SDK Platform-Tools）is installed
  • smartphone'sdeveloper optionsandusb debuggingis enabled
  • The PC and smartphone are connected with a USB cable,adb devices The smartphone is recognized by

If you haven't done the above yet, SDK Platform-Tools official page Please prepare by referring to the following.

Step 1: Prepare the script

The folder where you unzipped ADB (adb.exe in the folder withuninstall.ps1 Create a text file with the name , paste the following content, and save it. 

while ($true) {
    $pkg = Read-Host "Enter the package name (just enter to finish)"
    if ($pkg -eq "") { break }

    $result = adb shell pm uninstall -k --user 0 $pkg
    if ($result -match "Success") {
        $log = "$(Get-Date -Format 'yyyy/MM/dd HH:mm') $pkg"
        Add-Content -Path "uninstalled_apps.txt" -Value $log
        Write-Host "Delete completed: $pkg" -ForegroundColor Green
    } else {
        Write-Host "Delete failed: $result" -ForegroundColor Red
    }
}

Script behavior

  • Prompts repeatedly for package name
  • If the deletion was successful, enter the date, time and package name. uninstalled_apps.txt I will add it to
  • If deletion fails, the error details will be displayed (not recorded in the log)
  • Press Enter without entering anything to exit.

Step 2: Run the script

  1. ``Shift + right-click'' an empty space in the ADB folder and select ``Open PowerShell window here.''
  2. Type the command below and press Enter:
.\uninstall.ps1

If you receive an error related to "execution policy", please do the following first and then try again. 

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Step 3: Enter package name and delete

When the script starts, it will ask you to enter the package name. Package name of the app you want to remove (e.g.com.example.app) and press Enter.

How to find the package name:

  • Android 8.0 and above:"Settings" → "Apps" → "All apps" → Tap the target app to confirm
  • Android 7.x and below:Install Aplin from Google Play and check

「Deletion completed:〇〇” is displayed, it is successful. Continue to remove another app or just press Enter to exit.

Step 4: Check the log file

After every successful deletion, inside the ADB folder uninstalled_apps.txt will be created automatically. The contents are recorded in the following format. 

2026/05/17 14:32  com.example.bloatware
2026/05/17 14:33  com.carrier.app

By saving this file, you can always check what you deleted later.

(Supplement) How to restore deleted apps

You can restore deleted apps using the package name recorded in the log file (Android 7.0 and above). Execute the following command in PowerShell. 

adb shell cmd package install-existing package name

If "Success" is displayed, the restoration is complete.

*Restore is not possible on Android versions lower than 7.0. Please think carefully before deleting.

summary

By using a script, you can save yourself the trouble of entering commands manually each time, and you can also automatically keep a record of deleted apps. If you have a log file, you won't have to worry about "Did I delete that app?"

I hope this helps you organize your smartphone.
