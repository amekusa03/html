Android PDF Unlocker

Unlock a password-protected PDF using the set password.

About this Project

This is a wrapper app that unlocks a password-protected PDF using a preset password and passes it to a PDF app. Eliminate the hassle of entering passwords for password-protected PDF files such as pay slips that are sent every month.

As of May 2, 2026: It is now possible to view PDF within the app. Sorry for the self-evaluation, With the introduction of this app, you can now view PDFs very conveniently.

Video

Development Environment

  • Kotlin
  • Android SDK

Key Features

  • Password pre-registration: By registering a password within the app, you no longer need to enter it every time you open a PDF.
  • Automatic release: When you receive a password-protected PDF, it will be automatically unlocked using the registered password.
  • In-app PDF viewer: You can view the unlocked PDF directly within the app.

Known Issues / Out of Scope

  • PDFs can only be viewed within this app. Transfer to external PDF apps is not supported.
