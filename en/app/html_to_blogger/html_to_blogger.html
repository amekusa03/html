HTML to Blogger

Analyze local HTML files and images and post them to Blogger

About this Project

This is a desktop application that automatically processes local HTML files and images and posts them to Blogger. Clean HTML, add watermarks to images, add keywords and location information, and upload to Blogger.

Video

Development Environment

  • Python 3.x
  • BeautifulSoup4 (HTML Parsing)
  • Pillow (Image Processing)
  • Google API Client

Key Features

  • HTML cleansing: Remove unnecessary tags and attributes and convert to the optimal format for Blogger.
  • Batch processing of images: Upload local images and automatically compose watermarks.
  • Blogger API integration: Completely automate everything from authentication to posting and tagging.
