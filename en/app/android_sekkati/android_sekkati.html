About this Project

SekkaTi for Android is a reproduction of the Desktop version as an Android app. A memo pad for impatient people. Just take it out, write on it, and put it away.

Key Features

  • Smart records: Swipe through calendar-style cards to quickly take notes.
  • Modern design: It takes full advantage of Material 3 and features smooth card animations and gradient backgrounds.
  • Specifications horizontal expansion: The Desktop version was created for Android with ease of use in mind.
  • The base app is lunch_memo.

Technology Stack

  • Kotlin
  • Jetpack Compose (Material 3)
  • Room (SQLite)
  • WorkManager
  • Coroutines & Flow
  • MVVM
  • Gradle Version Catalog (libs.versions.toml)
  • KSP (Kotlin Symbol Processing)

Setup

  1. Open your project in Android Studio (recommended for Ladybug or newer).
  2. Run Gradle Sync.
  3. Run the app on your Android device or emulator.
