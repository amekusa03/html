ESP32 Air Conditioner Control

Automatically control the air conditioner with ESP to alleviate discomfort

1. Project overview

This project requires additional server equipment (mini PC, Raspberry The system monitors the room temperature and humidity of your home 24 hours a day using the microcontroller "ESP32-C3" and the high-precision temperature/humidity sensor "SHT30" that operate only on USB power without having to purchase a USB power supply (Pi, etc.), and carefully and automatically controls the air conditioner via the SwitchBot hub mini.This system maintains a comfortable indoor environment by alleviating indoor temperature irregularities such as being too cold (cold) or the air conditioner not working (hot).

2. System configuration/role division

This system performs local standalone control via the cloud (SwitchBot Web API).

[Indoor environment] ➔ (I2C) ➔ [ESP32-C3 + SHT30] (Single unit operation without base unit)
       │ (Wi-Fi / HTTPS)
       ▼
[SwitchBot Web API]
       │ (via cloud)
       ▼
[SwitchBot Hub Mini] ➔ (Infrared) ➔ [Air Conditioner]

2.1 Components and roles

  • Slave unit and control unit: ESP32-C3 development board(Power supply: 5V USB power supply only)
    • Acquire room temperature from SHT30 at 10-30 second intervals.
    • Judgment and management of control logic (hysteresis).
    • Send HTTPS requests (control commands) directly to SwitchBot Web API via Wi-Fi.
  • Sensor: SHT30(Temperature/humidity sensor module)
    • It is installed at a height above the line of activity (70 to 100 cm above the floor) to accurately measure temperature.
    • Physically placed several centimeters apart to avoid being affected by the communication heat generated by ESP32-C3.
  • Infrared repeater: SwitchBot Hub Mini(Already installed)
    • Receives a request from the cloud and sends an infrared signal to the air conditioner.
  • Target of operation: existing air conditioner
  • External service: SwitchBot Web API (v1.1)
    • Acquisition of device list and remote control of air conditioner (setAll command).

3. Hardware wiring (I2C connection)

Connect ESP32-C3 and SHT30 using the pin map below.

SHT30 side ESP32-C3 side Signal name/role remarks
VCC 3.3V power supply
GND GND ground
SDA GPIO 8 I2C data line Can be changed arbitrarily within the program
SCL GPIO 9 I2C clock line Can be changed arbitrarily within the program

*Note 1: To prevent instability due to inrush current (current spike) when connecting to Wi-Fi, use a high-quality USB cable.
*Note 2: GPIO 9 is the bootstrap pin of ESP32-C3. If the connected SHT30 module has a strong pull-down resistor, startup failure (transition to write mode) may occur. In that case, please change the I2C pin to another GPIO (e.g. SDA=GPIO 5, SCL=GPIO 6, etc.).

4. Control logic (air conditioner discomfort alleviation specification)

To prevent chattering (frequent on/off of air conditioner) and hunting phenomenon,Width from 1.5℃ to 2.0℃ (hysteresis)Performs two-state flag management with .

4.1 Automatic control rules

  • [Too cold (chilly) prevention trigger]
    • conditions: The room temperature is 24.5℃ or less and is currently in "normal mode (or before judgment)".
    • action: Air conditioner settings "Cooling 27℃ / Air volume: Quiet (breeze) / Wind direction: Upward" and change the state to "weak wind mode".
    • the purpose: Rather than completely cooling the room, use a slight breeze and upward blow to alleviate the direct hit of cold air.
  • [Ineffective (heat) countermeasure trigger]
    • conditions: The room temperature is 26.5℃ or higher , and is currently in "light wind mode".
    • action: Air conditioner settings "Cooling 25℃ / Air volume: Automatic" and change the state to "normal mode".
    • the purpose: Take a proactive approach and start cooling the room before it gets really hot.

4.2 Reliability and safety specifications

  • [Guard time (minimum transmission interval limit)]
    • In order to reduce the load on the compressor due to frequent air conditioner setting changes (chattering) and to avoid the SwitchBot API limit (up to 10,000 times per day), once a command is sent,Do not send the next command for at least 15 minutesSet up guard time.
  • [Persistence of status]
    • In order not to lose track of the status when the ESP32-C3 restarts due to a momentary power outage or Wi-Fi disconnection, the current control status (normal mode / weak wind mode) is stored in the built-in Flash memory (Preferences (library) at any time and save it.
    • If there is no saved state when starting up, for safety purposes, initialize to ``low wind mode if the room temperature is below 25.5 degrees Celsius, normal mode if the room temperature is above 25.5 degrees Celsius''.
  • [Failsafe in case of sensor abnormality]
    • I2C communication error with SHT30 or measurement value abnormality (NAN ), the system temporarily suspends control processing to prevent the air conditioner from running out of control, outputs an error to a serial monitor, etc., and waits.

5. Software specifications (communication and authentication)

Implement secure communication in ESP32-C3 that complies with SwitchBot Web API v1.1 specifications.

5.1 Preparing credentials

Obtain the following information from the smartphone app's "Developer Options" in advance and embed it into the program.

  • Token
  • Client Secret
  • Air conditioner device ID(Identify in advance using the list acquisition code)

5.2 API request specification

  • endpoint: https://api.switch-bot.com/v1.1/devices/{device_id}/commands
  • request method: POST
  • Required HTTP header:
    • Content-Type: application/json
    • Authorization: {Token}
    • sign: {HMAC-SHA256 signature string}(The combined characters of Secret, millisecond timestamp, and Nonce are HMAC-SHA256 hashed, and after Base64 encoding,All uppercase(converted to)
    • t: {millisecond timestamp}
    • nonce: {random string/UUID}
  • Send payload (JSON example): 
    {
  "command": "setAll",
  "parameter": "27,cool,1,on", 
  "commandType": "command"
}

    *(※parameter format: "Set temperature, operation mode, air volume, power status")*
