TagPlaylist Generator

Automatically generate genre-specific playlists from MP3 tag information.

About this Project

This is a tool developed to streamline the organization of your music library. Scans ID3 tags (genres) from a large number of MP3 files and categorizes them by genre. .m3u Create playlists automatically. It supports both GUI and CLI, and exports playlists with relative paths for portability.

Video

Development Environment

  • Python 3.10+
  • Mutagen (ID3 metadata library)
  • Tkinter (GUI)

Key Features

  • Automatic genre classification: Classify based on TCON frame with ID3v2 tag.
  • Relative path generation: Since it is written as a relative path from the playlist, it will not be corrupted even if you move the entire folder.
  • Compatible with both GUI/CLI: It has a drag-and-drop GUI and a CLI that is convenient for automation.
  • Recursive scan: All subfolders under the specified folder will also be searched.
