# HTML to Blogger

2026/01/30 / Python / Desktop Application

## overview

This is a desktop application that automatically processes local HTML files and images and posts them to Blogger.
Clean HTML, add watermarks to images, add keywords and location information, and upload to Blogger.

## Key Features

- **HTML Cleansing: **Remove unnecessary tags and attributes and convert to the best format for Blogger. 
- **Batch processing of images: **Automatically combine watermarks. 
- **Image upload: **View images to upload and manually upload. 
- **Blogger API integration: **Completely automates everything from authentication to posting and tagging.
