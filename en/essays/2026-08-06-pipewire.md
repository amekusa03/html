# A story about being addicted to the sound swamp - Chasing the "original sound" with Ubuntu -

To be honest, at first I just felt like the volume buttons weren't working.

I used to adjust the volume on my Ubuntu machine using keyboard shortcuts, but the moment I suddenly wondered, ``Is this really the volume I wanted?'' I bought a one-way ticket to the swamp. Before I knew it, I was staring at `pactl` and `pw-top`.

## First of all, the basic volume operation commands

If you want to adjust the volume in modern Ubuntu (PulseAudio/PipeWire environment), `pactl` is the standard entry point.

```bash
pactl set-sink-volume @DEFAULT_SINK@ +5%   # 5%上げる
pactl set-sink-volume @DEFAULT_SINK@ -5%   # 5%下げる
pactl set-sink-volume @DEFAULT_SINK@ 50%   # 50%に固定
pactl set-sink-mute @DEFAULT_SINK@ 1       # ミュート
```

Depending on your old environment or preference, you can also use ALSA-based `amixer`. To unmute, use `amixer sset Master on`, and to fix the volume, use `amixer sset Master 50%`.

My personal favorite is `alsamixer`. That screen where the volume bar pops up inside your device and you can use the arrow keys to adjust it. Perfect for when you don't even need to open the GUI. It's a promise that you'll forget to exit with `Esc` and think, "Oh, how do I close it?"

## A peek inside PipeWire

This is just a preface. Let's get to the main topic here.

First, check if your environment is working properly with PipeWire.

```bash
pactl info
```

If "Server name: PulseAudio (on PipeWire 1.x.x)" appears, it passes. Furthermore, if you hit `pw-top`, you can see the sampling rate, number of bits, and delay of the audio that is currently being played in real time. This was quite interesting, and I spent some time just watching the numbers move while playing videos or playing music. It may sound like a waste, but detours like this can deepen your understanding in the end.

## The bottom of the swamp called bit-perfect playback

Now, what I'm curious about is the suspicion that PipeWire may be converting audio to 48kHz without permission. CD sound sources are basically 44.1kHz, but if they are uniformly resampled to 48kHz, you will be hearing a sound that is slightly different from the original sound.

To prevent this, copy the configuration file to the user environment.

```bash
mkdir -p ~/.config/pipewire/
cp /usr/share/pipewire/pipewire.conf ~/.config/pipewire/
```

Then open it with `nano ~/.config/pipewire/pipewire.conf`, uncomment the following items, and list the rates that your DAC supports.

```bash
default.clock.allowed-rates = [ 44100 48000 88200 96000 192000 ]
```

After editing, restart PipeWire.

```bash
systemctl --user restart pipewire
```

This should allow the original sampling rate of the sound source to be output as is...but to be honest, this kind of setting just feels strange, and as someone who doesn't have a good ear, I'm mostly satisfied with the numerical logic. Still, there is something irresistible about the sound of being ``faithful to the original sound.''

## Maximize resampling quality

When playing sounds with different sampling rates at the same time, PipeWire performs internal correction calculations. The initial value of this precision is 4, but it can be raised to the maximum of 14.

```bash
mkdir -p ~/.config/pipewire/client.conf.d/
echo "stream.properties = { resample.quality = 14 }" > ~/.config/pipewire/client.conf.d/hires.conf
```

It's only a one-line file, but I think it's a setting that is quite effective.

## If you want to play surround sound as is

If you want to directly stream surround sound such as AC3 or DTS to your AV amplifier, it is most reliable to simply use `pavucontrol`.

```bash
sudo apt install pavucontrol
pavucontrol
```

You can turn on/off pass-through for compatible codecs from "Advanced" on the "Output Device" tab. It's faster to do this with the GUI than to do it all with commands.

## While reviewing the CD standards, proceed to the Rhythmbox settings.

To begin with, music CDs have a standard of 44.1kHz/16bit, which divides the sound 44,100 times per second and records the strength in 65,536 levels. When I look at the numbers again, I'm a little impressed by how much thought the engineers of the past put into deciding on this standard. In order to capture this original sound without degrading it, the 44100 permission setting on the PipeWire side comes into play.

Rhythmbox automatically takes over the PipeWire settings, so the only changes you need to make on the app side are the operational settings.

**Audio quality setting for CD import**
In the "Menu" > "Settings" > "Songs" tab, set the preferred format to `FLAC`. Lossless compression preserves the original CD sound without degrading sound quality, while also reducing storage capacity.

**Automatic volume equalization (replay gain)**
In the Settings > Playback tab, set Replay Gain to "Prefer Songs" or "Prefer Albums." You don't have to worry about the volume difference between songs.

**Smooth transitions between songs (crossfade)**
Also check the crossfade on the "Playback" tab and set it to around 2.0 seconds. This is a great feature for people who listen to albums in their entirety.

## Amulet for when you can't play

If you run into a wall where you can't play MP3 or AAC, chanting this will usually solve the problem.

```bash
sudo apt update
sudo apt install ubuntu-restricted-extras
```

During the installation, a screen asking you to agree to the terms will appear, so press the `Tab` key to select "OK" and `Enter`. I'm sure it's common for people to go back and forth looking for a mouse here.
