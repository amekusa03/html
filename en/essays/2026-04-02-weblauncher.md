# Android Web Launcher

2026/04/02 / kotlin

You can easily browse the web pages such as Amazon Store, Yahoo Shopping, Yahoo Auctions, etc.
I created "Rancha" which behaves like an Android app.

## About this Project

Rancha is an app that makes certain web pages behave like independent Android apps.
Manage up to 5 presets (drawer display) and unlimited home screen shortcuts.
This allows you to easily access specific web pages.
The name ``Rancha'' comes from the fact that this rancher was born in Shizuoka, a famous tea producing area.

## Key Features

- **Display a web page as a separate app: **Display a specific web page as a separate app on Android. 
- **User Friendly: **Easy to operate with intuitive UI.

## Out of Scope

- The function to display an arbitrary name on the drawer is currently not implemented. 
- We have confirmed that there is a behavior that depends on the launcher app, and that it can be changed with Nova Launcher, but cannot be changed with AQUOS HOME.
