# Android PDF Unlocker

2026/03/12 / kotlin

I found it troublesome to enter the password for the monthly pay slips, so I created a wrapper app that unlocks the password-protected PDF using the password set in the Android app and passes it to the PDF app.

## About this Project

A wrapper app that unlocks a password-protected PDF with the password set in an android app and passes it to the PDF app.
Eliminate the hassle of entering passwords for password-protected PDF files such as pay slips sent every month.

As of May 2, 2026: PDF viewing is possible within the app.
With the introduction of this app, you can now view PDFs very conveniently.

## Key Features

- **Password pre-registration: **By registering a password within the app, you no longer need to enter it every time you open the PDF.
- **Automatic unlock: **When you receive a password-protected PDF, it will be automatically unlocked using the registered password.
- **In-app PDF viewer: **You can view the unlocked PDF directly within the app.

## Out of Scope

- PDFs can only be viewed within this app. Transfer to external PDF apps is not supported.
