# Ubuntu introduction guide

2026/03/21  ubuntu/Windows

Linux distribution and use of stopped Windows

## About this Project

This is a project to reuse old Windows PCs as active terminals by replacing them with Ubuntu, a lightweight Linux distribution.
Reduce disposal costs and achieve green computing.

## Key Features

* **Speed-up:** Significantly reduces system resource consumption compared to Windows. 
* **Security:** From an unsupported OS to an environment where you can receive the latest security updates. 
* **Software Compatibility:** App setup for web browsing and document creation.
