# LocTime

2026/6/16 / kotlin

When I was at work, I sometimes didn't notice it was lunch time and was about to be late, so I created an app that notifies me when it's lunch time when I'm at work.

## About this Project

"LocTime" app sends notifications according to a specific location and time.

Notifications can be set flexibly to suit the user's lifestyle, such as notifying users of break times at work or work hours a few minutes beforehand.
We envision a scenario where you don't need it when you're at home, but you want time notifications when you're at work.
You can receive time-of-day notifications tailored to specific locations and times. The name "LocTime" means that it enables notifications tailored to various locations and times.

## Key Features

- **Location and time notifications: **Display notifications tailored to a specific location and time.
- **Specify location by address:** You can specify a more accurate location by entering an address.
- **User Friendly:** Intuitive UI makes it easy to operate.
