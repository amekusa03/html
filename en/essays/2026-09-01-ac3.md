# I created a GUI app that converts stereo sound sources to 5.1ch surround.

2026-9-1

## chance

While listening to music, I suddenly noticed that the subwoofer was playing.
Since the music files are mostly stereo, almost no signal reaches the subwoofer or rear speakers.
This is a waste. I want to make full use of the 5.1ch speaker system I have.

After doing some research, I found out that you can upmix stereo to 5.1ch using FFmpeg.
I thought it would be easier to use if I made it into a GUI app, so I created it using Python + CustomTkinter.

## what I made

![5.1ch conversion app](essays/2026-09-01-ac3.png)

A GUI application that converts stereo sound sources such as MP3 to **AC-3 (Dolby Digital compatible)** 5.1ch.

-  **Adjust mix with sliders** (Center/Rear/LFE ratio, delay, cutoff frequency)
-  **3 types of one-click presets** (movie/live music/voice emphasis)
-  **Batch conversion** (multiple files/folders at once)
-  **Dark/Light Mode**
-  **Real-time FFmpeg log display**

## How upmix works

Split the stereo L/R signal using FFmpeg's `filter_complex` and generate each channel.

| Channel | Original signal | Role |
|---|---|---|
| FL / FR | L, R as is | Front left and right |
| FC (Center) | `(L + R) × 0.707` | Vocal Dialogue |
| LFE (subwoofer) | `lowpass(L + R)` | Deep bass |
| SL (surround left) | `L - R` (phase difference) + delay | Ambient sound |
| SR (Surround Right) | `R - L` (Phase Difference) + Delay | Ambient Sound |

The key is to use the L-R phase difference for the surround channels, so that the sound with a stereo feel comes out from the rear.

## Code points

Tkinter is single-threaded, so touching the UI directly from a background FFmpeg worker will crash.
Avoided by polling `queue.Queue` + `after()`.

I also ran into a Python trap where a closure inside the `for` loop fixes the loop variable to its final value.
It seems to be the norm to capture with default arguments.
