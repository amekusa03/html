# Image for net v3

2026/06/23 / C# / Avalonia UI / Windows,Linux,macOS

Created to learn multi-OS with .Net.
It is also designed to be practical when uploading images to the Internet.

## About this Project

**ver2.0** added preview images. **ver3.0** added a batch editing function. 
**EXIF information deletion: **Remove shooting information to protect privacy. **Add watermark:**

* Adjusting text and position (four corners)
* Setting color, font size, and opacity
* Automatic selection of system font (Japanese compatible)
**Uses Avalonia UI:** Cross-platform compatibility based on .NET 8 provides a light operation experience on Windows, Linux, and macOS.

## Key Features

* **Personal information protection:** Remove personal information (EXIF data) contained in images in bulk.
* **Watermark compatible with Japanese:** Automatically recognizes the system font and synthesizes a watermark with freely adjusted opacity and color.
* **Uses Avalonia UI:** Cross-platform compatibility based on .NET 8 provides a light operating feel.
