# Major update of Lunch Memo to version 2.0

2026.07.01 / Kotlin / Jetpack Compose

---

## Make daily input easier

Lunch Memo is an Android app that allows you to stylishly manage your daily lunch plans and records in a calendar format.

Up until now, it was a simple memo pad that you could type in freely, but as you manually enter the same menu items like ``ramen'' and ``udon'' every day, it gradually becomes a chore.
We decided to make a major update this time because we wanted to be able to easily input menus that we often eat with just a tap.

## Redesign to 3-component configuration

Moving away from just free input notes, records can now be structured by dividing them into the following three components.

- **Select**: You can instantly select pre-registered items (such as ``Ramen'' or ``Curry'') by tapping them.
- **Numbers**: Record numerical values ​​such as amount and lunch satisfaction level (rating).
- **Text**: Free notes such as special notes of the day.

The settings screen has also been enhanced, allowing you to enable or disable these components to suit your preferences and edit the list of options.

## Big changes under the hood: migration and serialization

Along with this change to the UI and input structure, the data model has also been significantly updated.

- **Room Database Migration (v4)**: Safely migrate to a table configuration compatible with new components.
- **Serialize settings with GSON**: Serialize and securely persist the settings and list of choices for each component.

Due to the change in the database structure, we took great care in implementing the migration to avoid destroying existing users' data, but we were able to successfully update to 2.0 without any interruptions.

## Main features

- **Smart Tracking**: Swipe through calendar-style cards to quickly jot down what you had for lunch.
- **Lunch notification**: Every day at 12:00, you will be notified of that day's lunch memo. Solve the question, “What am I going to eat today?”
- **Modern Design**: Fully compatible with Material 3, featuring smooth card animations and gradient backgrounds.
