# Github translated into English

## 2026-09-12

## background

When I was looking for interesting projects on Githib, I noticed that people were searching in English.
Up until now, I had been writing the About in Japanese, and I realized that this was not a good idea.

Therefore, I changed the display language of Github to English.

## work

However, the number of repositories exceeds 60, and I would like to support multiple languages ​​for the About, README, and if possible, the app itself, and just thinking about it makes me dizzy.
However, when I tried it, I was able to finish it faster than expected by translating the About and README using scripts, modifying the app's UI to be either fixed in English or in multiple languages, and creating a pattern for the work.
