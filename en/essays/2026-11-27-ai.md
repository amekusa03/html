# Getting Started with Local AI, Even Now: Setting Up a Chat Environment on Your Computer Using Ollama and the Lightweight Gemma Model

2026-11-27

## Better late than never—I’ll give it a try here.

Talk of large language models (LLMs) has become commonplace, and we’ve entered an era where anyone can easily use high-performance AI through cloud services.

Amid all this, I happened to hear that “it seems AI that runs on a local environment (local LLM) has become quite easy to set up these days.” I remember that just setting up the environment used to be quite a hassle, but when I looked into it, it seems that using a tool called “Ollama” allows you to complete the setup with just a few lines of commands.

I heard that even on my own PC (running a 4th-generation Core i5 or similar), ultra-lightweight models in the 1B to 2B class run at a practical speed. Since there was no reason not to give it a try, I decided to actually install it.

## Installation Instructions

Setup is surprisingly simple and basically takes just two steps.

### 1. Installing Ollama

First, open a terminal and run the following command (if prompted for a password, enter it).

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

Simply run the command, and both the Ollama application and the background service will be set up all at once.

### 2. Downloading and Launching the Model

Next, specify the model you want to run and launch it. This time, to match the specs of my machine, I tried out “Gemma,” a lightweight model released by Google.

**Latest lightweight models (such as the Gemma 4 E2B; for devices with 8 GB of RAM or more):**
```bash
ollama run gemma4:e2b
```

**An even lighter model (Gemma 3 1B—runs smoothly at about 800 MB):**
```bash
ollama run gemma3:1b
```

Model data downloads automatically only the first time the program is run; once the download is complete, the terminal switches to a prompt where you can interact with the program.

### Basic Commands

The main operations performed in the terminal are as follows.

- **To end the chat**: Type `/bye` and press Enter
- **Restart**: Run `ollama run gemma4:e2b` again (Starting with the second time, it will launch immediately without needing to download anything.)
- **Deleting Unneeded Models**: `ollama rm gemma4:e2b`

## Tips for Everyday Use: Creating Custom Shortcuts

It's a bit of a hassle to open the Terminal and type in commands every single time I use it. So, I created a shortcut (a `.desktop` file) that lets me launch it with a single click from the list of apps on my desktop.

If you run the following command in the Terminal, "Gemma 4" will be added to the list of applications.

```bash
mkdir -p ~/.local/share/applications
cat << 'EOF' > ~/.local/share/applications/gemma4.desktop
[Desktop Entry]
Name=Gemma 4
Comment=Local AI Chat with Ollama
Exec=ollama run gemma4:e2b
Icon=utilities-terminal
Terminal=true
Type=Application
Categories=Utility;
EOF
```

Because `Terminal=true` is specified, clicking the icon automatically opens a terminal window, which then displays the interface for interacting with the local AI.

## Conclusion

When you actually try it out, there’s no waiting for a cloud connection, and the feeling of getting a response right from your local machine—even when the network is down—is, after all, somehow exciting.

Even on a machine with limited specs, it’s perfectly practical if you’re willing to compromise on its intended use and model size. Whether it’s for brainstorming ideas or polishing a piece of writing, it’s the kind of tool you’ll want to keep close at hand for everyday use.
