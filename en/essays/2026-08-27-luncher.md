# Linux has a lot of CLI, so I made a GUI launcher.

2026-08-27

## chance

It's been a while since I started using Linux, but compared to Windows, I still notice that there are a lot of command line operations. Each time I look up the command for the program I want to use, I type it into the terminal. This in itself is not a big deal once you get used to it, but if you are used to a GUI that can be operated easily with a mouse, it can be a little stressful.

I don't want to talk about which one is better. I think the ideal would be to be able to give an OK to either. So, I decided to try making my own application launcher on Linux, which is what Windows would call an application launcher.

## Launching a Python script

The first thing I started with was managing Python scripts. It was a pain to type `python3 アプリ名` every time. By creating a GUI using Qt (C++) and registering a Python script, you can start and stop it with a single button.

![PythonLauncher](essays/2026-08-27-luncher-01.png)

## Video conversion GUI

The next thing I worked on was a wrapper for ffmpeg.

```
ffmpeg [入力前オプション] -i <入力ファイル> [出力オプション] <出力ファイル>
```

There were so many combinations of options that it was tedious to research them each time. I also created a GUI using Python, and was able to perform the conversion by simply selecting the settings.

![PythonConvertMp4](essays/2026-08-27-luncher-02.png)

## What I was able to do

Start the launcher, select video conversion, and press the start button. Now that's all there is to it. Even as a former Windows user, I think it has become a little easier to use.
