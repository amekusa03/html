# I created a tool to easily switch PipeWire upmix.

2026-9-2

## chance

Continuing from yesterday, I was playing around with Ubuntu's sound.

In the previous article, I created a stereo → 5.1ch conversion application using FFmpeg, but that is just a file conversion. Wouldn't it be more convenient if you could upmix in real time while playing YouTube or a music player?

After doing some research, I found that PipeWire has an upmix function built in as standard. By rewriting the configuration file, you can convert the stereo sound source being played back to 5.1ch and output it from the speakers. However, editing the configuration file and restarting PipeWire is a hassle, so it is not something that can be easily switched.

I thought, ``Let's make it possible to switch this in one go with a GUI,'' and decided to create it using Python.

## what I made

![upmix_switcher](essays/2026-09-02-upmix.png)

A GUI tool that allows you to enable/disable PipeWire's 5.1ch upmix with one click.

- **One-Click Toggle**: Instantly toggle between enabling upmix and restoring standard 2ch direct output.
- **Preset function**:
  - **Standard (PSD Standard)**: Default balanced surround.
  - **Movie/Surround Emphasis**: Emphasizes the powerful deep bass and the surrounding feeling of the rear speakers.
  - **Music/Natural Spread**: Adds a natural sense of stereo spaciousness while suppressing heavy bass.
  - **Simple method**: Upmix using simple calculations.
  - **Custom**: Settings when manually adjusting each parameter.
- **Advanced parameter adjustment**:
  - Upmix method (`psd` / `simple` / `none`)
  - Subwoofer LFE cutoff frequency (40Hz to 200Hz)
  - Rear speaker delay (0.0ms~50.0ms)
  - Center FC cutoff frequency (0Hz~20000Hz)
  - Stereo wideness (Stereo Wide: 0.00 to 1.00)
- **Built-in speaker test**: 6ch `speaker-test` can be executed with one tap.

## structure

Just write the upmix parameters in the PipeWire configuration file (under `/etc/pipewire/pipewire.conf.d/`) and reflect them in `systemctl --user restart pipewire`. It sounds simple, but wrapping it in a GUI has made it much easier to use.

Presets are combinations of parameters defined in advance, and you can simply switch between them when watching a movie or listening to music.
