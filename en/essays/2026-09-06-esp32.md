# I was told that I don't bother looking at the web, so I tried attaching a screen to the ESP32.

2026-09-06

## background

Previously, I created a smart sensor that uses the ESP32-C3 to measure temperature and illuminance, which can be checked from a smartphone via a web browser. Personally, I was satisfied with how convenient it was to be able to see the room temperature at hand at any time, but my family gave me very realistic and silent feedback.

"It's a pain to have to take out my smartphone and open the web screen."

...It's just as you said. Temperature is only meaningful if you can tell it by just looking at it.

However, in case something like this were to happen, I secretly included a Web API (`/api/sensor`) in the previous firmware that allows you to pull sensor values ​​from the outside in JSON. So this time, I decided to pull out another ESP32 with a 1.9-inch LCD and create a ``dedicated desk monitor'' that acquires sensor values ​​via API and displays them all the time.

![LCD display image](essays/2026-09-06-esp32.png)

## Main functions and UI details

### 1. Cooperation with local web API
- Access the sensor terminal via mDNS (`http://esp32-switchbot.local/api/sensor`) to avoid problems even if the IP address changes.
- It periodically obtains JSON, parses the room temperature and brightness, and reflects it on the screen.

### 2. Dark theme UI with emphasis on visibility
- **320 x 170 horizontal screen layout**: The main feature, ``temperature (TEMP)'', is highlighted in an extra-large font in the center of the screen so that it can be understood at a glance even on a small 1.9-inch screen.
- **Illuminance display**: The lower row displays the brightness (BRIGHTNESS / LUX) in real time.
- **Modern color scheme**: Finished in a dark theme that makes it easy to see without making too much of an impression even if it is placed in a corner of the room.

### 3. Bonus NTP time synchronization
- Since I'm connected to Wi-Fi, I also want a watch, so I used NTP (`esp_netif_sntp`) to obtain Japan Standard Time (JST, UTC+9).
- The year, month, day, day of the week, and time are now displayed accurately at the top of the screen.

## Ending: A tragedy born of visualization

With this, ``an environment where you can always know the room temperature just by turning your gaze'' has been successfully completed. I installed it in a prominent place in my living room and grinned as I looked at the beautifully lit LCD screen...

As a result of being able to accurately see the room temperature in real time, my family saw the numbers and said, ``Oh, it's cool enough now,'' and simply turned off the air conditioner.

It seems that ``visualization'' of temperature sometimes evokes an unexpected awareness of power saving. It looks like the battle to hold on to the air conditioner remote control will begin before the room gets too hot and humid again.
