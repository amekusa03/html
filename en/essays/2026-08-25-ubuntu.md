# Summary of steps to install Ubuntu on Windows PC

2026-8-25: Revised

Steps to create a USB installation media for Ubuntu on a Windows PC and create a dual boot environment with Windows

## Advance preparation

Before installing Ubuntu, prepare the following:

- Windows PC
- USB memory of 8GB or more
  - The contents of the USB will be erased, so back up any necessary data in advance.
- internet connection
- free storage
  - At least 25GB for Ubuntu, preferably 50GB or more
- backup
  - Be sure to back up important Windows files just in case.

## Obtain the Ubuntu ISO file

・ Access the Ubuntu official website
・Select Ubuntu Desktop LTS version
・Download the ISO file

· supplement

- The LTS version has long-term support and is highly stable.
- Unless there is a special reason, the latest LTS version is fine.

## Create USB installation media

Rufus is easy to use on Windows.

procedure

・Download and start Rufus
・Insert the USB memory into the PC
- Set the following in Rufus
   - Device: USB memory to use
   - Boot type: Select the downloaded Ubuntu ISO file
   - Partition configuration:
     - Usually GPT
   - Target system:
     - Usually UEFI
・Press start
- If a warning appears, check the content and proceed.
- Safely remove the USB when finished

· Note

- Most modern PCs are UEFI + GPT.
- Older PCs with Legacy BIOS/MBR may have different settings.


## Perform advance settings on the Windows side

Before dual booting, make some preparations on the Windows side.

### Disable fast startup

If Windows' fast startup is enabled, Ubuntu may not be able to safely handle Windows partitions.

procedure

・Open the control panel
・Power options
・Select power button behavior
- Change settings that are currently unavailable
- Uncheck Enable fast startup
・Save

### Check BitLocker

If BitLocker is enabled, you may experience problems when performing partition operations or changing boot settings.

- Check if BitLocker is enabled
- If enabled, save the recovery key if necessary
- If you are unsure, pause before working.

### Make free space for Ubuntu

Shrink Windows disk space to create unallocated space for Ubuntu.

procedure

- Right click on Start
・Disk management
・Right-click the drive containing Windows (usually C:)
- Volume reduction
・Enter the amount of space you want to reserve for Ubuntu
   - Minimum 25GB
   - Recommended 50GB or more
- It is OK if there is unallocated space after shrinking.

・ Important

- Please leave it as unallocated space.
- Do not format it as a new drive in Windows.


## Boot from USB

Boot your PC using the Ubuntu USB you created.

procedure

・Insert the USB memory into the PC
・Restart your PC
- Open boot menu at startup
   - Example: F12, F11, Esc, F9 etc.
   - Varies depending on manufacturer
- Select USB memory and start
- Proceed when the Ubuntu boot menu appears.

If it doesn't work

- Check if USB boot is enabled in BIOS/UEFI settings
- Secure Boot will work as is in most cases, but may require adjustment depending on the environment.

## Try Ubuntu

It is safe to choose Try Ubuntu instead of installing it immediately after booting.

Check points:

- keyboard
- Wi-Fi
- Screen display
- touch pad
- sound

If there are no problems, run Install Ubuntu on the desktop.

## Install Ubuntu in dual boot with Windows

This is the real deal.

### Proceed with basic settings

In the installer select:

- language
- keyboard layout
- network connection
- Typical installation / Minimal installation
  - Normal installation is usually OK.

### Select installation type

Ideally, you would have the following options:

- Installing Ubuntu with Windows Boot Manager

If you see this, it's easy to select it.

If this option appears

- Decide how much space to allocate to Ubuntu using the slider etc.
- If you proceed as is, it will often be set automatically.

### If you don't see a co-located installation

In that case, use Something else (manual partition).

Example of required partition

Create the following in the unallocated space.

- root (/)
  - ext4
  - 20-30GB or more
- swap
  - Nowadays it is often not necessary
  - If you don't have much memory, you can reserve a few GB.
- home (/home) (optional)
  - If you want to separate the data, allocate the remaining capacity.

Simple configuration example

- allocate most of the total to /
- Sometimes I don't create swap and leave it to Ubuntu's automatic configuration.

Bootloader installation location

Normally, choose a disk that has an EFI System Partition.  
Example: /dev/nvme0n1 or /dev/sda

It is common to select the entire disk rather than individual partitions.

## Time zone and user creation

Configure the following during installation:

- time zone
- username
- PC name
- password

Note

In Ubuntu, you will need to enter a password for administrator tasks, so make it difficult to forget.

## Reboot after installation completes

- Reboot after installation is complete.
・Remove the USB memory when prompted
- The GRUB menu may be displayed after rebooting.

GRUB typically gives you the following choices:

- Ubuntu
- Windows Boot Manager

Dual boot is now complete.

## What to do after first startup

After starting Ubuntu, we recommend that you update it first.

`bash
sudo apt update
sudo apt upgrade -y
`

If necessary, also do the following:

- Confirmation of Japanese input
- Check additional drivers
- Introduction of browsers and development tools
- Check time synchronization

## Common troubles

Windows does not appear in the boot menu

- Check the boot order of UEFI settings
- It may be improved by updating os-prober or GRUB after starting Ubuntu.

Can't boot from USB

- Check if Rufus settings match UEFI/GPT
- Try another USB port
- Enable USB boot in BIOS/UEFI

Disk not visible during installation

- Intel RST/RAID mode may be affected
- AHCI may be required in BIOS  
  However, if you change this, Windows may not start, so be careful.

Problems related to Secure Boot

- Depending on the environment, disabling Secure Boot may improve the situation.
- However, it is usually supported by Ubuntu.

Asked for BitLocker recovery key

- This may occur after changing the startup settings.
- Be sure to write down your recovery key in advance.

---

## Points to proceed safely

- Always back up important data
- Keep aside your BitLocker recovery key
- Disable Windows fast startup
- Leave space for Ubuntu unallocated in Windows
- If you are unsure, first try Ubuntu to check if it works.
- If possible, make sure that you can view the information on another device such as a smartphone during the procedure.

## Summary of shortest steps

・Download Ubuntu ISO
- Create USB installation media with Rufus
- Disable fast startup on Windows
- Create unallocated space for Ubuntu in Disk Management
- Boot from USB
・Start the Ubuntu installer
- Select co-installation with Windows
- Reboot and select Ubuntu/Windows from GRUB

## Supplement: Recommended policies for beginners

If in doubt, the following policy is safe.

- Ubuntu is LTS version
- Rufus for USB creation
- For partitions, first give priority to co-installation with Windows.
- Use manual partitioning only when co-installation is not possible
