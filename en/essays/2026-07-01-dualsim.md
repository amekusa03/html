## I looked into it

The query for `NetworkStatsManager` has an argument called `subscriberId`. This is the key to identify the SIM.

Get the list of active SIMs with `SubscriptionManager` and query each with `subscriberId` to get the usage amount for each SIM. The structure is simple.

```kotlin
val subs = subscriptionManager.activeSubscriptionInfoList
for (sub in subs) {
    val tm = telephonyManager.createForSubscriptionId(sub.subscriptionId)
    val id = tm.subscriberId
    // NetworkStatsManager でクエリ
}
```
