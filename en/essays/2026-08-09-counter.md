# Summary of visitor counter construction using Vercel Redis (KV) + Serverless API

## 1. Background/Challenges

- **Conventional configuration**: Obtain and display the number of visitors using the external service "CounterAPI (v1)".
- **Problem Occurred**: CounterAPI v1 API has been completely deprecated (HTTP 410 Gone), so the count on the screen stops at `—` (error display).
- **Countermeasure**: Eliminate dependence on external services and switch to in-house counter using Vercel's free tier function (**Redis database + Serverless API Function**).

![Connect Redis Database](<essays/2026-08-09-counter.png>)

## 2. System configuration and mechanism

```flowchart
[ ブラウザ (index.html) ]
       │
       │  1. fetch('/api/counter?up=true')  ※新規セッション時のみ
       ▼
[ Vercel API Function (api/counter.js) ]
       │
       │  2. INCR visitors (または GET)
       ▼
[ Vercel Redis データベース (REDIS_URL) ]
```

### ① Front end (`index.html`)

- Call the `/api/counter` endpoint in the same domain.
- Use `sessionStorage` to monitor duplicate accesses, and request a count up by adding the `?up=true` parameter only when creating a new session.

### ② Backend (`api/counter.js`)

- Vercel's Node.js Serverless Function.
- Access Redis using the environment variables `REDIS_URL` (`redis://` / `rediss://`) automatically assigned by Vercel Integration (`redis-bisque-anchor`).
- Lightweight zero-dependency implementation without adding any external npm packages.

---

## 3. Benefits

- **Completely free ($0/month)**: Operated within the Redis Free framework of the Vercel Hobby plan.
- **Highly reliable**: Not affected by external third-party API deprecation or service termination.
- **CORS-free**: Communication is fast and safe because it uses the same domain API (`/api/counter`) of the own site.
