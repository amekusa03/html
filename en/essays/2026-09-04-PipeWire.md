# Added PipeWire settings

2026-9-4

## chance

When I was looking into the configuration file for PipeWire, the Arch Linux sound server, I realized that the settings I had been using for 5.1ch upmixing could actually do the same thing with PipeWire itself.

I took the opportunity to look at the other parameters, and found a number of interesting things: sampling rate, buffer size, resample quality, microphone automatic gain... As I kept rewriting the configuration files by hand, restarting, and checking, I began to think that it would be much easier to do this with a GUI.

The result is a GUI tool that allows you to manage PipeWire's main parameters using tabs.

## what I made

![PipeWire GUI tools](essays/2026-09-04-PipeWire.png)

### Upmix & speaker volume

You can adjust the 5.1ch upmix parameters with the slider. It is a form that incorporates the functions of the previous upmix tool as is.

In addition, we have added a function that automatically equalizes the speaker volume balance using microphone measurements. Play a test sound from each channel in turn, and align all speakers at the listening position based on the volume picked up by the microphone. The system allows measurements to be taken at low volume (15%) even at night when loud sounds cannot be produced.

### Mike & AGC

Added a real-time level meter for microphone input and a function to create a virtual microphone using WebRTC DSP. You can specify it as a "microphone with noise suppression/AGC applied" for OBS and Discord input.

There is also a mode where Python controls the microphone gain in real time using AGC. Automatically follows the target volume and sets a silence threshold to prevent environmental noise from being accidentally amplified.

### Clock & sampling rate

Parameters that are directly connected to PipeWire operations can be operated all at once, such as sampling rate settings (44.1kHz to 384kHz), buffer size (Quantum) selection, and resample quality slider adjustments.

### Real-time monitoring & configuration file editing

There are also tabs that allow you to monitor streams using `pw-top`, display PipeWire logs using `journalctl`, and directly check and edit generated configuration files using the built-in editor.

There is also a "Reset to Default" button that returns all settings to the initial system state at once.
