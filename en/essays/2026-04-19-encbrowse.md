# EncBrowse

2026/04/19 / Avalonia UI / C #

It is difficult to set access rights on inexpensive personal cloud web servers.
Therefore, images and text files are encrypted to strengthen the security of the files themselves.
Application to configure, manage, decrypt and view it.

## About this Project

This application allows authorized viewers to securely decrypt encrypted files and
Provide an application for viewing as a browser wrapper.
This allows you to safely manage and view files.
