# Naive-chan

2026.07.11/Ubuntu

## analysis

Why isn't Ubuntu popular? I want everyone to use it.
Yes, this is it. It's not popular because people aren't using Ubuntu.
If no one you know uses it, you probably won't even think about using it.

## carving

I'm sure I've had a similar experience before.
While everyone around me was playing on the Famicom, I was the only one playing on the MSX.
After a while, I had no one to talk to about MSX, and I naturally stopped using it.
