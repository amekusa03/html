# Grouping tool by music image

2026-08-25

## background

When I was researching noise removal for MP3 music files, I discovered a library called librosa.
This is a library specialized for music analysis, and can extract features called features.
Various features can be extracted, such as tempo (BPM), sense of energy (RMS), brightness of sound (spectral center of gravity), noise/percussiveness (zero crossing rate), tonality/harmony (chroma features), and timbre (MFCC).
So, I came up with an app that uses this to group music by mood.

## overview

![main window](essays/2026-08-25-mp3.png)

- **Desktop GUI (PySide6)**
  - **Folder visual selection**: Select target MP3/audio folder and playlist output destination
  - **Playlist reference & search**: List of created `.m3u` playlists
  - **Built-in audio player**: Play music
  - **Graph visualization display**: Display graph images of PCA scatter plot and elbow diagram

- **Multiple acoustic feature extraction (`librosa`)**
  - Tempo (BPM)
  - Energy (RMS/sound pressure sensation)
  - Brightness of sound (Spectral Centroid)
  - Noise/percussiveness (zero crossing rate: ZCR)
  - Tonality/chord structure (12-dimensional chroma feature)
  - Tone/Texture (MFCC 13 dimensions)

- **Automatic clustering & visualization**
  - Feature standardization using `StandardScaler`
  - Automatic grouping by mood using K-Means clustering
  - Automatic generation of cluster scatter plot (`clusters_pca.png`)
  - Verification of the optimal number of clusters using the elbow method graph (`elbow_curve.png`)


## solution
