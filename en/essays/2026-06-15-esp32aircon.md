# ESP32 Air Conditioner Control (+ SwitchBot Web API)

2026/06/15 / Arduino / ESP32 C3

It was hot and I turned on the air conditioner and it got cold within a few hours. In the meantime, it's going to get hot again. Repeating this is uneconomical
Therefore, we will use ESP32 and Switchbot to maintain a comfortable temperature.

## 1. Project overview

This project is a system that uses a microcontroller "ESP32-C3" and a high-precision temperature/humidity sensor "SHT30" that operate on USB power only, without purchasing additional server equipment, to monitor room temperature and humidity 24 hours a day, and automatically control the air conditioner via the SwitchBot hub mini, alleviating uneven indoor temperatures such as "too cold" or "the air conditioner not working (hot)" and maintaining a comfortable indoor environment.

## 2. System configuration/role division

This system performs local standalone control via the cloud (SwitchBot Web API).

```text
`[室内環境] ➔ (I2C) ➔ [ESP32-C3 ＋ SHT30] (親機なしで単体動作)
       │ (Wi-Fi / HTTPS)
       ▼
[SwitchBot Web API]
       │ (クラウド経由)
       ▼
[SwitchBot ハブミニ] ➔ (赤外線) ➔ [エアコン] `
```

### 2.1 Components and roles

- **Slave unit and control unit: ESP32-C3 development board** (Power supply: 5V USB power supply only)
  - Acquire room temperature from SHT30 at 10-30 second intervals.
  - Judgment and management of control logic (hysteresis).
  - Send HTTPS requests (control commands) directly to SwitchBot Web API via Wi-Fi.

- **Sensor: SHT30** (temperature/humidity sensor module)
  - It is installed at a height above the line of activity (70 to 100 cm above the floor) to accurately measure temperature.
  - Physically placed several centimeters apart to avoid being affected by the communication heat generated by ESP32-C3.

- **Infrared repeater: SwitchBot hub mini** (already installed)
  - Receives a request from the cloud and sends an infrared signal to the air conditioner.

- **Operation target:**Existing air conditioner
- **External service: SwitchBot Web API (v1.1)**
  - Used to obtain a list of devices and remotely control the air conditioner (`setAll` command).

## 3. Hardware wiring (I2C connection)

Connect ESP32-C3 and SHT30 using the pin map below.

SHT30 side ESP32-C3 side Signal name/role Notes **VCC** **3.3V** Power supply **GND** **GND** Ground **SDA** **GPIO 8** I2C data line Can be changed arbitrarily within the program **SCL** **GPIO 9** I2C clock line Can be arbitrarily changed within the program

*Note 1: To prevent instability due to inrush current (current spike) when connecting to Wi-Fi, use a high-quality USB cable.
*Note 2: GPIO 9 is the bootstrap pin of ESP32-C3. If the connected SHT30 module has a strong pull-down resistor, startup failure (transition to write mode) may occur. In that case, please change the I2C pin to another GPIO (e.g. SDA=GPIO 5, SCL=GPIO 6, etc.).

## 4. Control logic (air conditioner discomfort alleviation specification)

In order to prevent chattering (frequent on/off of air conditioner) and hunting phenomenon, two-state flag management with **1.5℃~2.0℃ width (hysteresis)** is performed.

### 4.1 Automatic control rules

- **[Too cold (chilly) prevention trigger]**
  - **Condition**: When the room temperature drops to **24.5℃ or below** and is currently in "normal mode (or before judgment)".
  - **Action**: Change the air conditioner settings to **"Cooling 27℃ / Air volume: Quiet (light breeze) / Wind direction: Upward"** and change the state to "Low wind mode".
  - **Purpose**: Without completely cooling the room, use a slight breeze and upward blow to alleviate the direct hit of cold air.

- **[Ineffective (heat) countermeasure trigger]**
  - **Condition**: When the room temperature rises to **26.5℃ or above** and the current "low wind mode" is selected.
  - **Action**: Change the air conditioner settings to **"Cooling 25℃ / Airflow: Auto"** and change the state to "Normal mode".
  - **Purpose**: Preemptively start cooling the room before it gets really hot.

### 4.2 Reliability and safety specifications

- **[Guard time (minimum transmission interval limit)]**
  - In order to reduce the load on the compressor due to frequent air conditioner setting changes (chattering) and to avoid the SwitchBot API limit (up to 10,000 times per day), we will set up a guard time to prevent the next command from being sent for at least 15 minutes after sending a command.

- **[Persistence of status]**
  - The current control status (normal mode/low wind mode) is written and saved in the built-in Flash memory (`Preferences` library) at any time so that the status is not lost when the ESP32-C3 is restarted due to a momentary power outage or Wi-Fi disconnection.
  - If there is no saved state when starting up, for safety purposes, initialize to ``low wind mode if the room temperature is below 25.5 degrees Celsius, normal mode if the room temperature is above 25.5 degrees Celsius''.

- **[Failsafe in case of sensor abnormality]**
  - If an I2C communication error with the SHT30 or an abnormality in measured values ​​(`NAN`, etc.) is detected, control processing is temporarily suspended to prevent the air conditioner from running out of control, an error is output to the serial monitor, etc., and the system waits.

## 5. Software specifications (communication and authentication)

Implement secure communication in ESP32-C3 that complies with SwitchBot Web API v1.1 specifications.

### 5.1 Preparing credentials

Obtain the following information from the smartphone app's "Developer Options" in advance and embed it into the program.

- **Token**
- **Client Secret**
- **Air conditioner device ID** (identify in advance using the list acquisition code)

### 5.2 API request specification

- **Endpoint**: `https://api.switch-bot.com/v1.1/devices/{device_id}/commands`
- **Request method**: `POST`
- **Required HTTP headers**:
  - `Content-Type: application/json`
  - `Authorization: {Token}`
  - `sign: {HMAC-SHA256署名文字列}` (HMAC-SHA256 hash of the combined characters of Secret, millisecond timestamp, and Nonce, converted to **all uppercase** after Base64 encoding)
  - `t: {ミリ秒タイムスタンプ}`
  - `nonce: {ランダムな文字列/UUID}`

- **Send payload (JSON example)**:

```json
{
  "command": "setAll",
  "parameter": "27,cool,1,on",
  "commandType": "command"
}


*(※parameter書式: "設定温度,運転モード,風量,電源状態")*
