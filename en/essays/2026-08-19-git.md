# Forget about source control

2026-08-19

![GitGUI-summary](essays/2026-08-19-git.png)

## background

When I was doing this, I lost track of which project's source I was editing, and as a result, I sometimes forgot to manage the source. In order to solve these problems, I decided to combine them into one tool and asked AI to create it.

## overview

A Python GUI application that automatically searches multiple Git repositories under a specified parent folder, and allows you to check and operate each repository's current branch name, change status (Staged / Unstaged / Untracked / Conflict), Push/Pull synchronization status (Ahead / Behind), and latest commit information in a list.

## List of features/functions

### Fast multi-threaded automatic search

- High-speed search of the Git repository (`.git`) under the parent folder using parallel processing.
- Customizable search hierarchy (1 to 5 levels).
- Asynchronous design that keeps the GUI from stalling while scanning large repositories.

### Dashboard status display

- Real-time summary card display of total number of repositories, clean status, changes (requires action), and number of unpushed/unpulled repositories.
- Easy-to-understand color-coded tag display for each status (green: clean, yellow: changed, red: conflict).

### Incremental search & filtering

- Real-time filtering by entering keywords (repository name, branch name, path, commit message).
  - Status filters (All, Needs Attention/Changes, Clean, Not Pushed (Ahead), Not Pulled (Behind), Conflicted).
  - Click on each header of the table to sort in ascending or descending order.

- Useful actions & right-click menu
  - Double-click: Open a folder in the file manager.
  - Right-click menu:
    - Open a folder (File Manager)
    - Open in Terminal (Terminal)
    - Open in VS Code (VS Code)
    - Re-update the status of individual repositories
    - copy path

- Data output (export)
  - Detection and narrowing results can be output and saved in CSV or JSON format.

- No dependent packages
  - Works only with the Python standard library. No additional `pip install` required.
