# Add temperature sensor with ESP32-C3

2026-8-29

## background

Last time, I set up a web server on the ESP32-C3 and created a device that integrated the illuminance sensor and SwitchBot Smart Home. I still had some ports left, so I added a temperature sensor by connecting a B3950 10k NTC thermistor.

## overview

![web](essays/2026-08-29-esp32temp.png)

- **Temperature measurement**: Connect a B3950 10k NTC thermistor and 10kΩ pull-down resistor voltage divider to `GPIO3` (ADC1_CH3). Calculate the actual temperature using the B constant (3950K). Temperature offsets can be set from the web UI and are permanently saved in NVS.
- **SwitchBot API v1.1 Authentication**: Generate HMAC-SHA256 signature using `mbedtls`. Obtain millisecond precision timestamps using NTP (`esp_netif_sntp`) and use them for API requests.
- **mDNS compatible**: Accessible with `http://esp32-switchbot.local/`. Adopts a delegate hostname method that coexists with Matter's mDNS.
- **SoftAP fallback**: Automatically starts in AP mode (`ESP32-SwitchBot-Setup`, `192.168.4.1`) when Wi-Fi is not set. Settings are permanently saved in NVS.

## pin arrangement

| ESP32-C3 pin | Connection destination | Role |
| :--- | :--- | :--- |
| **3.3V** | One leg of CdS cell | Power supply |
| **GPIO1 (ADC1_CH1)** | Connection point between CdS cell and pull-down resistor (approximately 9.1kΩ) | ADC illuminance measurement input |
| **GPIO3 (ADC1_CH3)** | Connection point between B3950 thermistor and pull-down resistor (10kΩ) | ADC temperature measurement input |
| **GND** | One leg of the pull-down resistor (approximately 9.1kΩ) | Ground |
| **GPIO9** | Tact switch (short circuit to GND) | Press and hold for 3 seconds to factory reset |
