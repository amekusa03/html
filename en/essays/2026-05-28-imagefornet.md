# Android Image for net

2026/05/28 / kotlin

Image processing app that supports EXIF ​​information deletion and watermark addition for Android devices

## About this Project

Android Image for net is an Android app that allows you to easily protect privacy (remove EXIF ​​information) and add watermarks before posting images to the Internet. Compatible with Android 6.0 (API 23) or higher.

The purpose is to protect privacy when publishing images online and to help identify original content.

## Key Features

- **EXIF information removal**: Permanently removes metadata such as GPS location information, shooting date and time, camera model, etc.
- **Real-time watermark**: Free text can be set and placed at top left/top right/bottom left/bottom right
- **Customizable**: Adjust font color, size, and opacity and preview instantly.
- **Sharing function**: Processed images can be shared as is to other apps
- **Simple operation**: Simple flow of selecting an image from the gallery, editing it with an intuitive UI, and saving it.
