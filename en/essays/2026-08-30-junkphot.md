# Unwanted photo deletion app for Android smartphones

2026-8-30

## background

The other day, I created a desktop app that uses Python to sort and delete photos. This time I decided to try making one for Android smartphones. The logic is based on the same algorithm as the Python version, the GUI was rewritten for smartphones, and implemented in Kotlin.

## overview

<video controls src="essays/2026-08-30-junkphot.mp4" title="Title"></video>

- **Bokeh detection**: Calculate sharpness score using Laplacian variance. In cooperation with ML Kit Face Detection, it prioritizes focus on facial areas in portraits. Equipped with grid evaluation logic that prevents misjudgment of background blur.
- **Continuous photo organization**: Analyzes EXIF ​​shooting date and time with sub-second accuracy and automatically detects continuous shooting groups. The one image in the group with the best focus is retained as the recommended image.
- **Similar photo sorting**: Using 64-bit dhash and Hamming distance clustering, visually similar photos are grouped together regardless of the date and time they were taken.
- **Cache**: Parsed hash values ​​and scores are permanently cached in Room (SQLite). Subsequent scans are faster.
- **Folder selection**: You can individually select and scan any folder such as camera roll, LINE, downloads, etc.

## technology stack

- **Language**: Kotlin
- **Persistence**: Room
- **Image Loading**: Coil
- **Computer Vision**: Laplacian Variance, dHash
- **AI/ML**: ML Kit Face Detection
- **Metadata**: ExifInterface
- **Concurrency**: Coroutines & Flow

## thoughts

Although there are no fatal flaws, tuning is difficult because the threshold is set to a fixed value, and there is still room for improvement in detection accuracy.
