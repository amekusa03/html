# ESP32-C6-GEEK Carlogger (+ELM327)

2026/06/08 / Arduino / ESP32-C6-GEEK

A project to acquire, display, and save driving logs to SD via ELM327 using ESP32-C6-GEEK.

## overview

This is a project that uses ESP32-C6-GEEK (Waveshare) to connect to ELM327 via BLE (NimBLE) or Bluetooth Classic to acquire, display, and save driving logs to SD.

## Features

- **LCD real-time display**—Displays driving data
- **Save file**—Save 1 second log to SD card (CSV)

## hardware

Parts model number/remarks

- Microcontroller Waveshare ESP32-C6-GEEK
- LCD ST7789 (Built-in board 135×240px)
- I/F ELM327（Bluetooth Classic）

Simple connection example (please refer to board documentation for actual pin assignment):

- LCD (ST7789): On-board SPI (MOSI/MISO/SCLK/CS/DC/RESET)
- SD card: VSPI / SDMMC (this project assumes via SPI)
- ELM327: Bluetooth Classic connection (when using ESP32 standard)

## set up

The following steps (example) assume that this repository is placed in the project root. Please change the path depending on your environment.

### 1. Prepare your Bluetooth credentials

The MAC address and PIN required to connect the ELM327 are currently hardcoded in `main.cpp`. Please change the value according to the actual machine. In the future, we recommend externalizing it with a configuration file.

```ini
[ELM327]
mac=AA:BB:CC:DD:EE:FF
pin=1234
```

### 2. Preparing and building the development environment

```bash
# ESP-IDF の環境スクリプトを読み込む
source /home/kusa/esp/esp-idf/export.sh

# プロジェクトルートへ移動（例）
cd ~/ドキュメント/eSp32/carlog

# ターゲットを設定（必要な場合）
idf.py set-target esp32c6

# ビルド
idf.py build
```

Tip: If you have dependent packages (such as Python requirements), run `python -m pip install -r requirements.txt`.

### 3. Flash to device

```bash
# シリアルデバイス名は環境依存です（例: /dev/ttyACM0, /dev/ttyUSB0）。
idf.py -p /dev/ttyACM0 flash
```

## Log storage format (SD card)

Saving is assumed to be CSV. Outputs the elapsed time since the power was turned on instead of the date and time. Example header:

```h
`elapsed_ms,latitude,longitude,speed_kmh,rpm,engine_load,throttle_pos,voltage `
```

sample row

```h
`123456,35.6895,139.6917,48.2,2200,12.3,8.1,12.6 `
```

## Precautions/Troubleshooting

- If you cannot pair with the ELM327, check the power supply and serial settings (baud rate) on the ELM327 side.
- If your SD card is not recognized, please make sure the file system is formatted as FAT32.
