# Cleaning the GitHub repository

2026-09-08 / bash / GitHub CLI

## background

A friend told me, ``The number of public repositories on GitHub has increased.'' Admittedly, I had been working on a project that I had been secretly working on privately, and I was making it public, and I was adding new projects, so I was a little lax in managing it. There are also a few repositories that do not have descriptions or tags.

At first, I wrote detailed explanations one by one on the web. However, the number of repositories did not decrease easily, and as expected, it became troublesome. So I decided to write a bash script using GitHub CLI (`gh`) and clean it up all at once.

## solution

```sh
sudo apt install gh
```

### script

```sh
#!/bin/bash

set -euo pipefail

OWNER="amekusa03"
DRY_RUN=false
if [[ "${1:-}" == "--dry-run" ]]; then
  DRY_RUN=true
  echo "### DRY RUN モード：実際には変更しません ###"
fi

# repo|description|topic1,topic2,...
# ※ topics が空欄の行は Description のみ設定します
DATA=$(cat <<'EOF'
AdjustDisplay|Ubuntu向けディスプレイ視覚調整ツール（輝度・コントラスト・ガンマ・カラーバランス）|qt,cpp,ubuntu,display-calibration,linux
PipeWire-5.1ch-Upmix-Switcher|PipeWireで2chステレオを5.1chへアップミックス切替できるTkinter GUIツール|python,tkinter,pipewire,linux,audio
    :
    : 中略
    :
EOF
)

while IFS='|' read -r REPO DESC TOPICS; do
  [[ -z "$REPO" ]] && continue

  ARGS=()
  if [[ -n "$DESC" ]]; then
    ARGS+=(--description "$DESC")
  fi
  if [[ -n "$TOPICS" ]]; then
    IFS=',' read -ra TOPIC_ARR <<< "$TOPICS"
    for t in "${TOPIC_ARR[@]}"; do
      ARGS+=(--add-topic "$t")
    done
  fi

  if [[ ${#ARGS[@]} -eq 0 ]]; then
    continue
  fi

  echo "==> $OWNER/$REPO"
  echo "    gh repo edit $OWNER/$REPO ${ARGS[*]}"

  if [[ "$DRY_RUN" == false ]]; then
    gh repo edit "$OWNER/$REPO" "${ARGS[@]}"
  fi
done <<< "$DATA"

echo ""
echo "完了しました。"
```

### execution

```sh
chmod +x repo-maint.sh
```

First, check the contents with `--dry-run`.

```sh
bash repo-maint.sh --dry-run
```

If there is no problem, remove `--dry-run` and perform the actual execution.

```sh
bash repo-maint.sh
```

Now you can organize the descriptions and topic tags for all repositories at once. Writing a single script is much faster and easier to review than constantly clicking on web screens.
