# ESP32 world Clock for Wokwi

2026/02/26 / C / Arduino / ESP32 / Wokwi

An ESP32 table clock designed to run on the Wokwi simulator.
It is for learning purposes.
A world clock that displays time and date on an LCD1602 display. Time is synchronized via NTP.
