# Distributing Android Apps: The Story of How I Got My APK Installed

2026-11-16

## It's now ready for installation!

Previously, when I tried to distribute my self-developed Android app as an APK file, the OS’s security restrictions were so strict that I couldn’t even install the unofficial APK directly on my own smartphone. As a result, I’ve had no choice but to publish only the source code on GitHub until now.

However, yesterday, on a whim, I decided to create an APK file again and give it a try. Although a warning screen did appear, I was able to easily authorize the installation simply by following the on-screen instructions.

![Warning Screen During Installation](essays/2026-11-16-android.png)

## I asked an AI about the background

I wondered, “When did the specifications change?” So I asked the AI, and a plausible explanation began to emerge.

For Android 16, Google initially appeared to be moving toward stricter security measures that would block the installation of unverified apps (so-called “unofficial APKs”). However, due to strong backlash from developers and power users, the company reportedly reversed its policy starting in November 2025, easing the restrictions to a “process that displays a strict warning but allows users to approve the installation at their own discretion.”

As someone who enjoys creating small tools on my own, I’m truly grateful for this change in policy.

## Build and Release in One Step from the Linux Terminal

If you already have a repository with source code pushed to GitHub, simply running the following two commands in the Linux (Ubuntu) terminal will complete the entire process—from generating the APK to publishing it to GitHub Releases—in an instant.

```bash
# 1. デバッグ版APKのビルド
./gradlew app:assembleDebug

# 2. GitHub Releaseの作成とAPKのアップロード（GitHub CLI）
gh release create v2.0.1 app/build/outputs/apk/debug/app-debug.apk \
  --title "アプリ名 v2.0.1" \
  --notes "更新内容やリリースノート"
```

The ability to quickly take a project all the way to deployment using only the CLI—without having to go out of your way to launch the bulky Android Studio GUI—is a major advantage unique to development in a Linux environment.
