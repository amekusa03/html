# A Used Laptop for 15,000 Yen and Making Do with 256GB

2026-11-22

## How It All Began

I thought it would be convenient to be able to flash the ESP32 while on the go, so I bought a used laptop for 15,000 yen. However, it only had a 256GB SSD.

Around that time, prices for SSDs, HDDs, and USB flash drives had been rising steadily. Manufacturers were announcing price hikes one after another, and I even saw news reports that USB flash drives had gone up significantly in price. What’s more, it seems that all companies are predicting that supply shortages will continue for the foreseeable future.

It would be a waste to spend about the same amount of money on an SSD for a PC I bought for 15,000 yen.

## It All Started with a Failure

First, I tried to install ESP-IDF on Windows. However, the installation failed partway through. What's more, the leftover files are still taking up space on my drive.

When I tried to install Ubuntu in that state, I ran out of disk space. There was only about 10 GB of free space on the C: drive. I couldn't do anything with that.

The Windows version of ESP-IDF was larger than I expected. When you add the toolchain and Python environment, it ranges from a few GB to about 10 GB. That’s no small amount of space on a 256 GB SSD.

## The conclusion is: dual boot

After thinking it over, I decided to set up a dual-boot system using my current SSD.

On Windows, I use Word, email, and an app called PUZU to configure the DSP on my car stereo. Since it connects to the device via USB, I figured it would be safer to install Windows directly rather than using a virtual machine.

On the other hand, I'll leave development on the ESP-IDF to Ubuntu. Builds are fast, and the environment is stable. WSL is another option, but configuring USB is a hassle, and it takes up extra disk space.

So I'll keep Windows to a minimum and do my development on Ubuntu. Even with just 256 GB, this setup should work out just fine.

## Actually, I don't use it very often.

To begin with, I probably only use this laptop for about an hour a month.

When I think about it that way, I don’t see any real reason to buy a new SSD. Upgrading to a 512GB model would cost around 10,000 yen, even at the low end. Looking at current market prices, even used ones start at a few thousand yen. Even so, that’s a bit much to spend for just one hour of use per month.

If I really run out of storage space, I'll worry about it then. Fortunately, I can move my photos and videos to an external drive.

## What to Do Next

When I have some free time, I'll reset Windows. It's a cleaner solution, and it's more reliable than hunting down leftover files one by one.

Once it's initialized, install the PUZU app and test it. After that, shrink the C: drive and install Ubuntu. As long as you follow the steps in the right order, it shouldn't be too difficult.

If I could program the ESP32 while I'm out and about, it might open up a few more possibilities.

## Conclusion

It's not a bad thing to save money. But there are times when spending money makes things easier. In this case, since I don't use it very often, I chose not to spend the money.

I think we'll know in six months whether this decision was the right one. I'd like to write about it again then.
