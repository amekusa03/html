# 音楽ファイルの"見えないノイズ"を追いかけて 〜MP3検査アプリを作った話〜

2026-08-24

音楽を再生していると、ときどき「プツッ」と音が途切れる瞬間がある。
原因はわかっている——録音したMP3ファイルのどこかに問題がある。
だが、何百枚もあるアルバムの中から該当ファイルを耳で探し当てるのは、現実的ではない。
それならいっそ、ノイズを自動で検出できるアプリを作ってしまおうと思った。

## overview

**MP3 Noise Checker** は、Python + PyQt5 で開発したMP3音楽ファイル品質検査デスクトップアプリです。
音割れ・ポップノイズ・音飛び・DC オフセットの4種類のノイズを自動解析し、波形の可視化やID3タグ編集まで一括で行えます。

## Main features

### 🔍 4種ノイズ自動検出エンジン

- **音割れ / 飽和クリッピング**: 最大振幅に達している過大入力サンプル数を検出。
- **ポップ / クリックノイズ**: 隣接サンプル間の急激な変化（$dy/dt$）を解析し、パルスノイズの発生位置（`mm:ss.s`）を特定。
- **曲中の音飛び / 異常無音**: イントロ・アウトロを除く曲中に、指定秒数・指定dBFS以下の音抜けが発生していないかを検出。
- **DC オフセット偏り**: 直流成分バイアスのずれを検出。
- 検出結果は 0〜100 のリスクスコアと4段階ステータス（🟢 正常 / ⚠️ 要確認 / 🚨 ノイズ検出 / ❌ 破損）でカラー表示。

### ⚡ 解析結果の自動キャッシング (`noise_cache.json`)

解析済みのノイズ判定結果をファイルに永続保存。
アプリ再起動後も、ファイルの更新日時（mtime）が変わっていなければ、即座に前回の結果を復元・表示する。

### 🎚️ 5段階感度プリセット

| レベル | 用途 |
| -------- | ------ |
| Level 1: Ultra-Low | 完全破損・重度歪みのある音源のみ検出 |
| Level 2: Mild | 高音圧ロック・EDM音源向け |
| Level 3: Standard | バランス重視の標準判定（デフォルト） |
| Level 4: High | わずかな音割れ・クリック音もキャッチ |
| Level 5: Strict / Pro | アーカイブ・マスタリング用の最高精度検証 |
| Custom | ユーザー定義による手動パラメータ調整 |

### 📂 フォルダ / ファイル選択

- **`[📂 Open Folder...]`**: フォルダ全体を一発で開く。
- **`[🎵 Select MP3 Files...]`**: 複数のMP3ファイルを直接選択し、即座に解析。
- **`[Scan & Check Folder]`**: サブフォルダを含む全MP3を非同期でバックグラウンド一括走査。解析の一時停止・再開・中断も可能。

### 🌊 波形 & ノイズインスペクター

音声波形を描画し、ノイズ位置を視覚的に確認できる。
<font color='#f7768e'>■ クリッピング領域（赤色破線）</font>・<font color='#ff0055'>│ ポップ/クリックノイズ（赤色縦線）</font>・<font color='#e0af68'>■ 異常無音区間（黄色背景）</font>を色分け表示。
ノイズ箇所をクリックするとその位置から試聴再生（`QMediaPlayer`）できる。

### ✏️ ID3メタデータ編集 & ライブラリ整理

タイトル・アーティスト・アルバム・年・トラック番号・カバーアートの編集と、`[アーティスト]/[アルバム]/[曲名.mp3]` 構造への自動ライブラリ整理。

## solution

ポップノイズの検出が発端だったが、実際に問題のあるファイルの波形を見ると、サンプリング自体が失敗しているケースが多く含まれていた。
これまで気づかずに聴き続けていたのかと思うと、自分の耳がいかに寛容だったか、改めて証明された形になった。
