# Chasing the "invisible noise" in music files ~The story of creating an MP3 inspection app~

2026-08-24

When playing music, there are times when the sound cuts out.
I know the cause: There's something wrong with the recorded MP3 file.
However, it is not practical to use your ears to find the appropriate file among hundreds of albums.
In that case, I decided to create an app that can automatically detect noise.

## overview

**MP3 Noise Checker** is an MP3 music file quality inspection desktop application developed with Python + PyQt5.
It automatically analyzes four types of noise: cracking, pop noise, skipping, and DC offset, and allows you to visualize waveforms and edit ID3 tags all at once.

## Main features

### 🔍 4 types of noise automatic detection engine

- **Crackling/Saturation Clipping**: Detects excessive number of input samples reaching maximum amplitude.
- **Pop/click noise**: Analyzes sudden changes ($dy/dt$) between adjacent samples and identifies the location of pulse noise (`mm:ss.s`).
- **Sound skipping/abnormal silence during a song**: Detects if there is a sound dropout of less than the specified number of seconds and specified dBFS during the song, excluding the intro and outro.
- **DC offset bias**: Detects deviation in DC component bias.
- Detection results are displayed in color with a risk score from 0 to 100 and a 4-level status (🟢 Normal / ⚠️ Needs confirmation / 🚨 Noise detected / ❌ Damaged).

### ⚡ Automatic caching of analysis results (`noise_cache.json`)

Permanently save analyzed noise judgment results to a file.
Even after restarting the app, if the file modification time (mtime) has not changed, the previous result will be immediately restored and displayed.

### 🎚️ 5 sensitivity presets

| Level | Use |
| -------- | ------ |
| Level 1: Ultra-Low | Detects only completely damaged/severely distorted sound sources |
| Level 2: Mild | For high sound pressure rock/EDM sound sources |
| Level 3: Standard | Standard judgment with emphasis on balance (default) |
| Level 4: High | Catch even slight cracks and clicks |
| Level 5: Strict / Pro | Highest accuracy verification for archive mastering |
| Custom | User-defined manual parameter adjustment |

### 📂 Folder/file selection

- **`[📂 Open Folder...]`**: Open the entire folder in one shot.
- **`[🎵 Select MP3 Files...]`**: Directly select multiple MP3 files and instantly analyze them.
- **`[Scan & Check Folder]`**: Asynchronously scans all MP3s including subfolders in the background. It is also possible to pause, resume, and interrupt analysis.

### 🌊 Waveform & Noise Inspector

You can draw the audio waveform and visually check the noise location.
<font color='#f7768e'>■ Clipping area (red dashed line) </font>・<font color='#ff0055'>│ Pop/click noise (red vertical line) </font>・<font color='#e0af68'>■ Abnormal silent section (yellow background) </font> are displayed in different colors.
Click on the noise location to play the preview (`QMediaPlayer`) from that location.

### ✏️ ID3 metadata editing & library organization

Edit title, artist, album, year, track number, cover art, and automatically organize library into `[アーティスト]/[アルバム]/[曲名.mp3]` structure.

## solution

The problem started with the detection of pop noise, but when we actually looked at the waveforms of the files with the problem, we found that there were many cases where the sampling itself had failed.
I thought I had been listening to it without noticing it until now, but it proved once again how forgiving my ears were.
