# I tried displaying Android notifications on ESP32

Last time, we displayed notifications from Ubuntu to ESP32-C6-GEEK, but this time we tried displaying notifications from Android to ESP32-WROOM-32. The display is ST7789V3 (170x320).

## overview

The Ubuntu version used Wifi, but since this is Android, I decided to use Bluetooth Classic to send notifications. I can use this secretly at work, and I feel like it could be used as an alternative to a smartwatch. However, we decided to leave the simple Wifi function as well.

## background

To be honest, when creating the Android version, I had a hard time deciding whether to use Wifi or Bluetooth. In the end, I chose Bluetooth Classic because it was easy to use at work, and I could glance at it while driving (no staring, really). The reason I chose Classic instead of BLE was to reuse the resources since I used Classic last time.

![alt text](/en/essays/2026-07-31-androidESP32.png)

## solution

I had a track record of making it once with the WiFi version of Ubuntu, so it took shape faster than I expected. The only thing that stuck was that I couldn't connect because the device name was different from what I expected at the initial stage. This was easily resolved by displaying the information being sent on the Android screen to visualize what was happening. When you're in trouble, just try showing the contents on the screen.
