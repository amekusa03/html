# Since Linux has a lot of CLI, I created a GUI installer.

2026-08-31

## chance

Since Linux has a lot of CLI, this is the third installment of the GUI series.

Linux's App Center may seem convenient, but it's a bit of a problem when you actually use it. I don't know which apps are common, the instructions are in English, and I'm not sure if I should uninstall them or not. Therefore, I created a GUI installer that carefully selects and displays only frequently used applications.

![GUI](essays/2026-08-31-luncher.png)

## Features

- **Curated list**: Display only commonly used apps such as LibreOffice, VLC, GIMP, VS Code, Firefox, etc. System packages such as `lib*` / `*-dev` / `linux-*` are not released at all.
- **Search**: You can narrow down your search by app name or description in real time.
- **Install/Uninstall**: Execute `pkexec apt install` or remove with one button click.
- **Progress display**: Display apt's real-time output in a dialog.
- **Dark Theme**: Modern dark UI with custom QSS.
