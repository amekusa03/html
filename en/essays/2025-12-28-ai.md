# inspired by AI

2025-12-28

## Initially

Several decades ago, I discovered a programming language called LISP.
When I learned that it was also used in some AI research, I started thinking about trying it myself.
A few days later, I showed off the finished product to a friend, and while he thought it was interesting, my own evaluation was low.
I only give answers that I have defined, and I always give the same answers to the same questions. It felt like I was just hitting a wall.

## big data era

As time passed, I started working with big data, and every month I started running a system that took about 8 hours on the server.
At this point, even if the results were aggregated, only vague trends emerged, making it extremely difficult to make use of them.
I tried out an expensive server and was able to complete the process in about 4 hours, but
In terms of operation, the system was still set up at night and finished in the morning, so we gave up on it.
A long time ago, I heard that 2TB was enough to store the world's information, but the amount of data far exceeded that amount.

## at an exhibition

Looking for his next career path, he found a company specializing in big data analysis at an exhibition and visited it several times.
Once you give them the data, they will complete the analysis and make a proposal within a day. That's a remarkable result.
I immediately proposed using it, but it was rejected.
The reason is cost effectiveness.
It is true that one analysis costs more than one person-month.
Furthermore, even if the numbers that appear are correct, they may not be usable as a proposal.
If someone does it, they will finish coordinating with each department and come up with several proposals.
Also, only humans can come up with breakthrough proposals.
Unfortunately, I gave up on the data analysis system.
Later, at a software house, I found a system that could analyze data using NVIDIA graphics cards and a CUDA compiler.
Although it was effective, it exceeded the memory capacity of the graphics cards at the time, and no matter how we divided it up, it could not be accommodated, so it was decided that it was a disastrous failure.

## AI era

Since the beginning of this year, an environment has been created in which even users like me who don't spend a lot of money can use AI.
First, they helped me complete the proposal. I got decent results.

Next, I finally started developing it.
For fun, I instructed Copilot to create a web BBS using Firebase.
I purposely avoided giving instructions on which components to use.
Within a few minutes, I had the component set up, including the debugging environment, and the source code was written.
It's scary... Even after debugging, the instructions are still being executed properly.
When I review the source, I find it to be fairly well written.
My rating is 50 points. A score of 80 is enough to warrant a salary.
The reason why it didn't work is because I could only do what I was instructed to do. First of all, there are no comments. The naming is good. Although the functions have been divided, the structure is not reusable. What's more, the GUI looks too simple.
Even an amateur should be able to bring out a little more sex appeal.

## design

I judged that there was no point in creating a document with this structure, so I instructed them to make the design more stylish.
In addition, the design was instructed to create a CSS file and define it there.
This was because we were concerned that if we did not add this, functionality and design would become mixed up, resulting in an unbalanced system.
Copilot wrote the code in an instant without any hesitation.
When I try to run it, I get an error.
Although I was able to guess the general location of the problem, I felt troublesome and sent the details of the error to Copilot.
They apologized and fixed it, but the same error occurred again.
When I reported the error to Copilot again, something surprising happened.
I successfully modified the code and it became executable.
It even feels kind of endearing.
