2026/04/01 / Google Search Console / Vercel

## 1.vercel site

#### Site map creation

Create **sitemap.xml** and place it in the root folder. 
**sitemap.xml** is an XML file that indicates the pages to be searched, making it easier for search engines to recognize the pages on your site. 
There are various sitemap generators available online that can be easily generated by simply entering a URL.
If you ask Gemini, it will analyze your site structure and automatically generate the optimal sitemap. 

#### Site map registration

Set **https://amekusa.vercel.app/** in the property in Google Search Console 

- Indexing → Sitemap 
- Add a new sitemap: enter **sitemap.xml** and submit 
Initially, I got a "Failed to retrieve" error on Search Console.
Although it can be confirmed from the browser, crawler tools such as Gemini and Copilot also determined that the file does not exist. 
The cause was a bot block caused by Vercel's security settings.
The issue was resolved by changing (Save) the following settings from **Enabled for Standard Protection** to **Disabled** on the Vercel management screen.
However, this setting may reduce security, so we recommend reverting to **Enabled for Standard Protection**. 

As a result, Google Search Console now loads sitemap.xml successfully. 
This makes it easier for Google to crawl your site's pages, increasing your chances of appearing in search results.

## 2.Google Blogger sitemap settings

Google Blogger automatically generates sitemap.xml. 
You can access the sitemap by adding the blog URL + /sitemap.xml to Google Search Console. 

Example: https://amekusa03.blogspot.com/sitemap.xml

## 3. YouTube tag settings

Properly tagging your YouTube videos will help your videos appear for relevant search queries. 
Choosing tags that accurately describe the content of your video and including keywords in the title, description, and Show All tags will improve your SEO results. 

## supplement

#### Example sitemap.xml


```
`<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://amekusa.vercel.app/</loc>
    <lastmod>2024-06-01</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset> `
```

#### explanation

- **XML declaration: **Specifies the XML version and encoding. 
- **xmlns attribute: **Specifies the schema of the sitemap protocol. 
- **loc: **Specifies the absolute URL of the page. 
- **lastmod: **Last updated date. This will help search engines decide whether to re-crawl.
