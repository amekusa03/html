# Email Gemini

2026/04/16 Google Apps Script

I have an email environment, but when I can't use a browser or smartphone,
An app that allows you to send an email to yourself and receive Gemini's response via email.

## How to Use

1. Create a project on Google Cloud Platform and enable Gemini API. 
2. Obtain the API key and set it in the Google Apps Script project. 
3. Set up an email reception trigger with Google Apps Script and create a script that calls the Gemini API when an email with a specific subject or content is received. 
4. Implement the script to process the response from the Gemini API and send the appropriate reply email. 
5. Send a test email to confirm that the system is working properly.
