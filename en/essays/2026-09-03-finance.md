# Created a predictive model for stock prices and investment trusts

2026-09-03

## chance

Investing with NISA has now become commonplace, and online securities services are also expanding. However, it is difficult to ask friends for predictions, and the internet is overloaded with information. I wanted something to support my decisions, so I created a model that uses Python to acquire stock prices in real time and predict prices for the following day. I used Streamlit for the first time to make the display easier to see.

## Features

### Price prediction using AI (LightGBM) & technical analysis

Machine learning is used to predict the probability of price increases and decreases from the next day to several days later (1 to 5 days). It comprehensively evaluates indicators such as RSI, MACD, Bollinger Bands, moving average crosses, and ATR, and displays them on an interactive Plotly candlestick chart.

### Streamlit Dashboard

- Search for stocks, add stocks, and manage the list of registered stocks on the sidebar.
- You can list all stocks and check graphs, forecasts, and technical indicators.

## result

If it were this easy, no one would have a hard time. So, it doesn't hit. However, it seems to be a boost for individuals who buy and sell. I think the correct way to use it is to use it as a tool to support your own judgment, rather than relying on machine learning predictions as is.
