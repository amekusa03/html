# UbuntuをWindows PCに導入する手順まとめ

2026-8-25: 改定

Windows PCでUbuntuのUSBインストールメディアを作成し、Windowsとのデュアルブート環境を構築する手順

## 事前準備

Ubuntuを導入する前に、次を用意します。

- Windows PC
- 8GB以上のUSBメモリ
  - USBの中身は消えるので、必要なデータは事前にバックアップ
- インターネット接続
- 空きストレージ
  - Ubuntu用に最低でも25GB以上、できれば50GB以上
- バックアップ
  - 万一に備えて、Windowsの重要ファイルは必ずバックアップ

## UbuntuのISOファイルを入手する

・ Ubuntu公式サイトへアクセス
・ Ubuntu Desktop LTS版を選ぶ
・ ISOファイルをダウンロードする

・ 補足

- LTS版は長期サポートがあり、安定性が高いです。
- 特別な理由がなければ最新のLTS版で問題ありません。

## USBインストールメディアを作成する

WindowsではRufusを使うのが簡単です。

手順

・ Rufusをダウンロードして起動
・ USBメモリをPCに挿す
・ Rufusで以下を設定
   - デバイス: 使用するUSBメモリ
   - ブートの種類: ダウンロードしたUbuntuのISOファイルを選択
   - パーティション構成:
     - 通常はGPT
   - ターゲットシステム:
     - 通常はUEFI
・ スタートを押す
・ 警告が出たら内容を確認して進める
・ 完了したらUSBを安全に取り外す

・ 注意

- 最近のPCはほとんどUEFI + GPTです。
- 古いPCでLegacy BIOS / MBRの場合は設定が異なることがあります。


## Windows側の事前設定をする

デュアルブート前に、Windows側でいくつか準備します。

### 高速スタートアップを無効化する

Windowsの高速スタートアップが有効だと、Ubuntu側からWindowsパーティションを安全に扱えない場合があります。

手順

・ コントロールパネルを開く
・ 電源オプション
・ 電源ボタンの動作を選択する
・ 現在利用可能ではない設定を変更します
・ 高速スタートアップを有効にする のチェックを外す
・ 保存

### BitLockerの確認

BitLockerが有効だと、パーティション操作や起動設定変更時に問題になることがあります。

- BitLockerが有効か確認
- 有効なら、必要に応じて回復キーを控える
- 不安があれば、一時停止してから作業する

### Ubuntu用の空き領域を作る

Windowsのディスク領域を縮小して、Ubuntu用の未割り当て領域を作成します。

手順

・ スタートを右クリック
・ ディスクの管理
・ Windowsが入っているドライブ（通常は C: ）を右クリック
・ ボリュームの縮小
・ Ubuntu用に確保したい容量を入力
   - 最低25GB
   - 推奨50GB以上
・ 縮小後、未割り当て領域ができればOK

・ 重要

- 未割り当て領域のままにしてください。
- Windowsで新しいドライブとしてフォーマットしないでください。


## USBから起動する

作成したUbuntu USBを使ってPCを起動します。

手順

・ USBメモリをPCに挿す
・ PCを再起動
・ 起動時にブートメニューを開く
   - 例: F12, F11, Esc, F9 など
   - メーカーによって異なる
・ USBメモリを選択して起動
・ Ubuntuの起動メニューが表示されたら進む

うまくいかない場合

- BIOS/UEFI設定でUSBブートが有効か確認
- Secure Bootは多くの場合そのままでも動きますが、環境によっては調整が必要です

## Ubuntuを試す

起動後、いきなりインストールせずTry Ubuntuを選ぶと安心です。

確認ポイント:

- キーボード
- Wi-Fi
- 画面表示
- タッチパッド
- サウンド

問題なければデスクトップ上のInstall Ubuntuを実行します。

## UbuntuをWindowsとデュアルブートでインストールする

ここが本番です。

### 基本設定を進める

インストーラーで以下を選択します。

- 言語
- キーボードレイアウト
- ネットワーク接続
- 通常インストール / 最小インストール
  - 普通は通常インストールでOK

### インストール種類を選ぶ

理想的には次のような選択肢が出ます。

- Windows Boot Manager と共存して Ubuntu をインストール

これが表示されるなら、それを選ぶのが簡単です。

この選択肢が出る場合

- スライダーなどでUbuntuへ割り当てる容量を決める
- そのまま進めれば自動で設定されることが多いです

### 共存インストールが表示されない場合

その場合はSomething else（手動パーティション）を使います。

必要なパーティション例

未割り当て領域の中に以下を作成します。

- root (/)
  - ext4
  - 20〜30GB以上
- swap
  - 最近は必須ではないことも多い
  - メモリが少ないなら数GB確保してもよい
- home (/home)（任意）
  - データを分けたいなら残り容量を割り当て

シンプル構成の例

- / に全体の大部分を割り当てる
- swapは作らず、Ubuntuの自動設定に任せる場合もある

ブートローダーのインストール先

通常はEFI System Partitionを持つディスク本体を選びます。  
例: /dev/nvme0n1 や /dev/sda

個別のパーティションではなくディスク全体を選ぶのが一般的です。

## タイムゾーンとユーザー作成

インストール中に以下を設定します。

- タイムゾーン
- ユーザー名
- PC名
- パスワード

注意

Ubuntuでは管理者作業でパスワード入力が必要になるので、忘れにくいものにします。

## インストール完了後に再起動する

・ インストール完了後、再起動
・ 指示が出たらUSBメモリを抜く
・ 再起動後、GRUBメニューが表示されることがあります

GRUBでは通常、以下のような選択ができます。

- Ubuntu
- Windows Boot Manager

これでデュアルブート完了です。

## 初回起動後にやること

Ubuntu起動後は、まず更新しておくのがおすすめです。

`bash
sudo apt update
sudo apt upgrade -y
`

必要に応じて以下も行います。

- 日本語入力の確認
- 追加ドライバーの確認
- ブラウザや開発ツールの導入
- 時刻同期の確認

## よくあるトラブル

Windowsが起動メニューに出ない

- UEFI設定の起動順を確認
- Ubuntu起動後に os-prober やGRUB更新で改善する場合あり

USBから起動できない

- Rufusの設定がUEFI/GPTと合っているか確認
- 別のUSBポートを試す
- BIOS/UEFIでUSB起動を有効化

インストール中にディスクが見えない

- Intel RST / RAID モードが影響することがある
- BIOSでAHCIが必要な場合あり  
  ただし、ここを変更するとWindowsが起動しなくなるケースもあるので慎重に対応

Secure Boot関連で問題が出る

- 環境によってはSecure Bootを無効化すると改善
- ただし通常はUbuntuが対応していることも多い

BitLocker回復キーを求められる

- 起動設定変更後に起きることがあります
- 事前に回復キーを必ず控えておく

---

## 安全に進めるためのポイント

- 重要データは必ずバックアップ
- BitLocker回復キーを控える
- Windowsの高速スタートアップを無効化
- Ubuntu用領域はWindowsで未割り当てにしておく
- 不安ならまずTry Ubuntuで動作確認
- 可能なら手順中にスマホなど別端末で情報を見られるようにしておく

---

## 最短手順の要約

・ Ubuntu ISOをダウンロード
・ RufusでUSBインストールメディアを作成
・ Windowsで高速スタートアップを無効化
・ ディスク管理でUbuntu用の未割り当て領域を作成
・ USBから起動
・ Ubuntuインストーラーを開始
・ Windowsと共存インストールを選ぶ
・ 再起動してGRUBからUbuntu/Windowsを選ぶ

---

## 補足: 初心者向けのおすすめ方針

もし迷ったら、次の方針が安全です。

- UbuntuはLTS版
- USB作成はRufus
- パーティションはまずWindowsと共存インストールを優先
- 手動パーティションは、共存インストールが出ないときだけ使う
