# AndroidのSwitchBotアプリを自作した

2026-08-13

## 純正アプリへの不満という、ありふれたモチベーション

AndroidのSwitchBotアプリは、私には少し面倒だった。リモコンを選択して、それからON/OFF操作、という2ステップの構造になっていて、素早く使いたいときに素早く使えない。寝ながら照明を消したいだけなのに、画面を2回タップしなければならないのは、地味にストレスになる。

そこで、SwitchBot Open API v1.1を活用して、Androidから直接スマートホームデバイスを操作するアプリを自作することにした。

![SmartSwitchBot](essays/2026-08-13-smartswichbot.png)

## 例の認証という儀式

SwitchBotのAPIはHMAC-SHA256による署名付きリクエストを要求してくる。前回ESP32で実装したときも同じ儀式を踏んだが、今回はAndroid（Kotlin）側での実装となる。ミリ秒精度のタイムスタンプとランダムなnonceを組み合わせて署名を生成する、というプロセスは相変わらずだ。実装自体は難しくはないが、ひとつでも値がずれると即座に401を返してくれるため、緊張感がある。

## 操作1ステップへの執念

UIはカード型のデザインを採用した。デバイスの種類（ボット、プラグ、エアコン、テレビなど）によって専用の操作パネルが切り替わり、それぞれに必要なコントロールだけが表示される。エアコンなら温度調節と停止ボタン、テレビならチャンネルと音量と電源、ボットやプラグはシンプルにON/OFFのみ。登録済みのシーンもワンタップで実行できる。

API TokenとSecretはアプリ内の設定ダイアログから登録・更新でき、端末内のDataStoreに保存される。面倒な設定も最初の一度だけで済む。

最終的に、「タップ1回でデバイスを操作する」という当初の目的は達成できた。些細なことだが、毎日使うものは些細なことほど大事だと思っている。
