# Vercel Redis (KV) ＋ Serverless API による訪問者数カウンター構築まとめ

## 1. 経緯・課題

- **従来構成**: 外部サービス「CounterAPI (v1)」を利用して訪問者数を取得・表示。
- **問題発生**: CounterAPI の v1 API が完全に廃止（HTTP 410 Gone）されたため、画面上のカウントが `—`（エラー表示）で停止。
- **対策**: 外部サービスへの依存を排除し、Vercel の無料枠機能（**Redis データベース ＋ Serverless API Function**）を用いた自前カウンターに切り替え。

![Connect Redis Database](<essays/2026-08-09-counter.png>)

## 2. システム構成と仕組み

```
[ ブラウザ (index.html) ]
       │
       │  1. fetch('/api/counter?up=true')  ※新規セッション時のみ
       ▼
[ Vercel API Function (api/counter.js) ]
       │
       │  2. INCR visitors (または GET)
       ▼
[ Vercel Redis データベース (REDIS_URL) ]
```

### ① フロントエンド (`index.html`)

- 同一ドメインの `/api/counter` エンドポイントを呼び出します。
- `sessionStorage` を用いて重複アクセスを監視し、新規セッション時のみ `?up=true` パラメータを付与してカウントアップを要求します。

### ② バックエンド (`api/counter.js`)

- Vercel の Node.js Serverless Function。
- Vercel Integration（`redis-bisque-anchor`）で自動付与された環境変数 `REDIS_URL`（`redis://` / `rediss://`）を利用して Redis へアクセスします。
- 外部 npm パッケージを追加しない軽量なゼロ・ディペンデンシー実装。

---

## 3. メリット

- **完全無料（$0/month）**: Vercel Hobby プランの Redis Free 枠内で運用。
- **高信頼性**: 外部のサードパーティ API 廃止やサービス終了の影響を受けない。
- **CORSフリー**: 自サイトの同ドメイン API (`/api/counter`) のため通信が高速・安全。
