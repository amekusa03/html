# LinuxてCLIが多いのでGUIランチャー作った

2026-08-27

## きっかけ

Linuxを使い始めてしばらく経つが、Windowsと比べると、やはりコマンドライン操作の多さが目につく。使いたいプログラムのコマンドをそのたびに調べ、ターミナルに打ち込む。それ自体は慣れればどうということもないのだが、マウスでポチポチ操作できるGUIに慣れた身には、小さなストレスが積もっていくものだ。

どちらが良いか、という話はしたくない。どちらでもOKを出せるのが理想だと思っている。そこで、Windowsでいうアプリケーションランチャーを、Linux上に自分で作ってみることにした。

## Pythonスクリプトの起動

まず手をつけたのは、Pythonスクリプトの管理だ。`python3 アプリ名` と毎回打つのが、地味に面倒だった。Qt（C++）でGUIを作り、Pythonスクリプトを登録しておけば、ボタンひとつで起動・停止できるようにした。

## 動画変換のGUI化

次に取り組んだのが、ffmpegのラッパーだ。

```
ffmpeg [入力前オプション] -i <入力ファイル> [出力オプション] <出力ファイル>
```

オプションの組み合わせが多く、毎回調べながら打つのが億劫だった。こちらもPythonでGUIを作り、設定をポチポチ選ぶだけで変換を実行できるようにした。

## できたこと

ランチャーを起動し、動画変換を選んで、開始ボタンを押す。それだけで済むようになった。元Windowsユーザーでも、少しは使いやすくなったんじゃないかと思っている。
