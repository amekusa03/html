# USBカメラが無い

2026-08-03 / 開発

## 経緯

何年か前にUSBカメラを買いましたが、安モノだったせいかすぐに壊れました。
まぁ全然使ってなかったので問題無かったのですが、
しかしたまには使いたいんですよね。
でも、今更買うのもなんだし。

## 創る

そうです、無いものは作るのが正解です。
とは言っても、0からは作れませんが。

手元にあるカメラは、コンデジとスマホ。
スマホなら何とかなるのではと思いつきました。
（優秀なコンデジならUSBで繋ぐだけでウェブカメラになるようですが、手元のものは対応していないので仕方ありません。）

![alt text](essays/2026-08-03-cam.png)

## やっぱり

今回はAndroid側は画像を送信する処理に徹しました。
どちらかと言えば、Ubuntu側が本番といったところでしょうか。
このあたりの動画関連の処理は、どうしてもffmpegを使うしか思いつきません。
その他、今回は下記の通りてんこ盛りです。

```bash
sudo apt install v4l2loopback-dkms v4l2loopback-utils ffmpeg adb v4l-utils
```

その他は README.md に書いて完了。
