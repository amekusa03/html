# Androidアプリの配布 〜 APKがインストールできるようになっていた話 〜

2026-11-16

## インストールできるようになっている！

以前、自作のAndroidアプリをAPKファイルとして配布しようと試したときは、OS側のセキュリティ制限があまりに厳しく、自分のスマートフォンですら野良APKをそのままインストールすることができなかった。そのため、これまではやむを得ずGitHubでソースコードのみを公開する形をとっていた。

ところが昨日、ふと思い立って再びAPKファイルを作って試してみたところ、警告画面こそ出るものの、画面の手順に沿って進めるだけであっさりとインストールを許可することができたのである。

![インストール時の警告画面](essays/2026-11-16-android.png)

## 背景をAIに聞いてみた

「いつの間に仕様が変わったのだろう？」と気になり、AIに尋ねてみたところ、合点のいく背景が見えてきた。

Android 16の世代において、Googleは当初、未検証アプリ（いわゆる野良APK）のインストールを厳しくブロックする方向でセキュリティ強化を進めていたらしい。しかし、それに対して開発者や上級ユーザーから強い反発の声が上がったため、2025年11月以降に方針を転換し、「厳格な警告を表示したうえでユーザーの意思でインストールを許可できるフロー」へと制限が緩和されたとのことだった。

個人で小さなツールを作って楽しんでいる身としては、実にありがたい方針転換である。

## Linuxターミナルから一発でビルド＆リリースする

すでにGitHubへソースコードをプッシュしているリポジトリであれば、Linux（Ubuntu）のターミナルから以下の2つのコマンドを実行するだけで、APKの生成からGitHub Releaseへの公開まで一瞬で完了する。

```bash
# 1. デバッグ版APKのビルド
./gradlew app:assembleDebug

# 2. GitHub Releaseの作成とAPKのアップロード（GitHub CLI）
gh release create v2.0.1 app/build/outputs/apk/debug/app-debug.apk \
  --title "アプリ名 v2.0.1" \
  --notes "更新内容やリリースノート"
```

重たいAndroid StudioのGUIをわざわざ立ち上げることなく、CLIだけでサクッと配信まで持っていけるこの身軽さは、Linux環境での開発ならではの大きな魅力だ。

## これからはAPKでも配信します

これなら、わざわざPCにAndroid Studioを入れてビルドしなくても、スマートフォン単体で手軽にアプリを試してもらうことができる。
今後は自作アプリをメンテナンスしたタイミングで、ソースコードとあわせてAPKパッケージもこの場で公開していこうと思う。
