# PySide6をQtCreatorで触ってみる

2026-08-26

## ついやってしまうこと

PySide6の開発にQt Creatorを使っている。便利なのだが、毎回やらかすことがある。

QtDesignerでスロットを作ろうとしてしまうのだ。C++の感覚が抜けないのか、ボタンを配置するたびにシグナル・スロットエディタに手が伸びる。するとビルド時に「ヘッダファイルがない」と怒られる。そうだ、Pythonにヘッダなどない。

![QtCreator](essays/2026-08-26-pyside6.png)

## 正しいやり方

方針はシンプルだ。QtDesignerでは画面レイアウトだけに専念する。ボタンなどの配置と `objectName`（例：`pushButton_submit`）の設定だけ行い、スロットには手を出さない。

シグナルとスロットの接続は、Pythonのコード側で行う。

```python
from PySide6.QtCore import Slot
from PySide6.QtWidgets import QApplication, QMainWindow
from mainwindow import Ui_MainWindow

class MainWindow(QMainWindow, Ui_MainWindow):
    def __init__(self):
        super().__init__()
        self.setupUi(self)
        self.pushButton.clicked.connect(self.on_submit_clicked)  # self から直接アクセス

    @Slot()
    def on_submit_clicked(self):
        print("ボタンがクリックされました")

if __name__ == "__main__":
    app = QApplication([])
    window = MainWindow()
    window.show()
    app.exec()
```

注意点が一つ。`self.ui.pushButton` ではなく `self.pushButton` と書く。`Ui_MainWindow` を多重継承しているので、`ui` を介さずに直接アクセスできる。

## もう一つの方法

命名規則を使った自動接続という手もある。スロットのメソッド名を `on_オブジェクト名_シグナル名` という形にすると、`connect` を明示的に書かなくて済む。

```python
from PySide6.QtWidgets import QApplication, QMainWindow
from mainwindow import Ui_MainWindow

class MainWindow(QMainWindow, Ui_MainWindow):
    def __init__(self):
        super().__init__()
        self.setupUi(self)

    def on_pushButton_clicked(self):
        print("ボタンがクリックされました")

if __name__ == "__main__":
    app = QApplication([])
    window = MainWindow()
    window.show()
    app.exec()
```

派生クラスで名前を合わせるだけでよい。仕組みとしては納得できるが、命名ルールに縛られるのが少し気になる。

## ひとこと
