# ステレオ音源を5.1chサラウンドに変換するGUIアプリを作った

2026-9-1

## きっかけ

音楽を聴いていて、ふとサブウーファーが遊んでいることに気づいた。
音楽ファイルはほぼステレオなので、サブウーファーやリアスピーカーにはほとんど信号が届いていない。
これはもったいない。せっかくある5.1chスピーカーシステムを、全部使いたい。

調べてみると、FFmpegでステレオを5.1chにアップミックスできることがわかった。
ついでにGUIアプリにすれば使いやすいと思い、Python + CustomTkinterで作ってみた。

## 作ったもの

![5.1ch変換アプリ](essays/2026-09-01-ac3.png)

MP3などのステレオ音源を **AC-3 (Dolby Digital互換)** の5.1chに変換するGUIアプリ。

-  **スライダーでミックス調整**（センター / リア / LFE比率・ディレイ・カットオフ周波数）
-  **ワンクリックプリセット 3種**（映画 / 音楽ライブ / ボイス重視）
-  **バッチ変換**（複数ファイル・フォルダ一括）
-  **ダーク / ライトモード**
-  **リアルタイムFFmpegログ表示**

## アップミックスの仕組み

ステレオのL/R信号をFFmpegの `filter_complex` で分岐させ、各チャンネルを生成する。

| チャンネル | 元の信号 | 役割 |
|---|---|---|
| FL / FR | L, R そのまま | フロント左右 |
| FC（センター） | `(L + R) × 0.707` | ボーカル・ダイアログ |
| LFE（サブウーファー） | `lowpass(L + R)` | 重低音 |
| SL（サラウンド左） | `L - R`（位相差）+ ディレイ | 環境音 |
| SR（サラウンド右） | `R - L`（位相差）+ ディレイ | 環境音 |

サラウンドチャンネルにL-Rの位相差を使うのがポイントで、ステレオ感のある音がリアから出るようになる。

## コードのポイント

Tkinterはシングルスレッドなので、バックグラウンドのFFmpegワーカーから直接UIを触るとクラッシュする。
`queue.Queue` + `after()` ポーリングで回避している。

また、`for`ループ内のクロージャでループ変数が最終値に固定されるPythonの罠も踏んだ。
デフォルト引数でキャプチャするのが定石らしい。
