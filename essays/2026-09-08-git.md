# GitHubリポジトリの大掃除

2026-09-08 / bash / GitHub CLI

## 経緯

友人から「GitHubの公開リポジトリが増えたね」と言われた。確かに、個人でこっそり進めていたプロジェクトに体裁を整えて公開したり、新規に作ったものを追加したりしたので、管理が少し手薄になっていた。説明文やタグがついていないリポジトリもチラホラ見受けられる。

最初は1つずつ、Web上で丁寧に説明を書いていた。しかしリポジトリの数はなかなか減らず、さすがに面倒くさくなってきた。そこで GitHub CLI (`gh`) を使ったbashスクリプトを書いて、一気に片付けることにした。

## 解決

### GitHub CLI のインストール

```sh
sudo apt install gh
```

### ログイン

```sh
gh auth login
```

### スクリプト

```sh
#!/bin/bash

set -euo pipefail

OWNER="amekusa03"
DRY_RUN=false
if [[ "${1:-}" == "--dry-run" ]]; then
  DRY_RUN=true
  echo "### DRY RUN モード：実際には変更しません ###"
fi

# repo|description|topic1,topic2,...
# ※ topics が空欄の行は Description のみ設定します
DATA=$(cat <<'EOF'
AdjustDisplay|Ubuntu向けディスプレイ視覚調整ツール（輝度・コントラスト・ガンマ・カラーバランス）|qt,cpp,ubuntu,display-calibration,linux
PipeWire-5.1ch-Upmix-Switcher|PipeWireで2chステレオを5.1chへアップミックス切替できるTkinter GUIツール|python,tkinter,pipewire,linux,audio
    :
    : 中略
    :
EOF
)

while IFS='|' read -r REPO DESC TOPICS; do
  [[ -z "$REPO" ]] && continue

  ARGS=()
  if [[ -n "$DESC" ]]; then
    ARGS+=(--description "$DESC")
  fi
  if [[ -n "$TOPICS" ]]; then
    IFS=',' read -ra TOPIC_ARR <<< "$TOPICS"
    for t in "${TOPIC_ARR[@]}"; do
      ARGS+=(--add-topic "$t")
    done
  fi

  if [[ ${#ARGS[@]} -eq 0 ]]; then
    continue
  fi

  echo "==> $OWNER/$REPO"
  echo "    gh repo edit $OWNER/$REPO ${ARGS[*]}"

  if [[ "$DRY_RUN" == false ]]; then
    gh repo edit "$OWNER/$REPO" "${ARGS[@]}"
  fi
done <<< "$DATA"

echo ""
echo "完了しました。"
```

### 実行

```sh
chmod +x repo-maint.sh
```

まずは `--dry-run` で内容を確認する。

```sh
bash repo-maint.sh --dry-run
```

問題がなければ、`--dry-run` を外して本番実行する。

```sh
bash repo-maint.sh
```

これで、全リポジトリの説明文とトピックタグを一括で整備できた。地道にWeb画面をポチポチするより、スクリプト1本のほうがずっと速くて、見直しも楽だ。
