# 今更ながら始めるローカルAI 〜Ollamaと軽量Gemmaで手元にチャット環境を作る〜

2026-11-27

## 今更ながら、手元で動かしてみる

世間では大規模言語モデル（LLM）の話題が当たり前になり、クラウドサービスを使えば誰でも手軽に高性能なAIを使える時代になった。

そんな中、ふと「ローカル環境で動かすAI（ローカルLLM）も、今はかなり導入が簡単になっているらしい」という話を耳にした。以前は環境構築だけでも一苦労だった記憶があるが、調べてみると「Ollama」というツールを使えば、コマンド数行でセットアップが完了するらしい。

手元のPC（第4世代Core i5などの環境）でも、1B〜2Bクラスの超軽量モデルなら実用的な速度で動くとのこと。それなら試してみない手はない、ということで実際に導入してみることにした。

## 導入手順

セットアップは驚くほどシンプルで、基本的に2ステップで完了する。

### 1. Ollamaのインストール

まずはターミナルを開き、以下のコマンドを実行する（途中でパスワードを求められたら入力する）。

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

実行するだけで、Ollama本体とバックグラウンドで動くサービスが一括でセットアップされる。

### 2. モデルのダウンロードと起動

続いて、動かしたいモデルを指定して起動する。今回は手元のスペックに合わせて、Googleが公開している軽量モデル「Gemma」を試してみた。

**最新の軽量モデル（Gemma 4 E2B など・メモリ8GB〜向け）：**
```bash
ollama run gemma4:e2b
```

**さらに軽量なモデル（Gemma 3 1B・約800MBで軽快に動作）：**
```bash
ollama run gemma3:1b
```

初回実行時のみモデルデータのダウンロードが自動的に始まり、完了するとそのままターミナル上で対話ができるプロンプトに切り替わる。

### 基本的な操作コマンド

ターミナル上での主な操作は以下の通り。

- **チャットを終了する**: `/bye` と入力してEnter
- **再起動する**: 再び `ollama run gemma4:e2b` を実行（2回目以降はダウンロード不要で即座に起動する）
- **不要になったモデルの削除**: `ollama rm gemma4:e2b`

## 日常使いのための工夫：専用ショートカットの作成

使うたびに毎回ターミナルを開いてコマンドを打ち込むのは少し億劫だ。そこで、デスクトップのアプリ一覧からワンクリックで起動できるショートカット（`.desktop`ファイル）を作成した。

以下のコマンドをターミナルで実行すると、アプリケーション一覧に「Gemma 4」が登録される。

```bash
mkdir -p ~/.local/share/applications
cat << 'EOF' > ~/.local/share/applications/gemma4.desktop
[Desktop Entry]
Name=Gemma 4
Comment=Local AI Chat with Ollama
Exec=ollama run gemma4:e2b
Icon=utilities-terminal
Terminal=true
Type=Application
Categories=Utility;
EOF
```

`Terminal=true` を指定しているため、アイコンをクリックすると自動的にターミナルウィンドウが立ち上がり、そのままローカルAIとの対話画面が立ち上がる。

## おわりに

実際に動かしてみると、クラウドのような通信待ちもなく、ネットワークが切れていても手元のマシンだけで言葉が返ってくる感覚は、やはりどこかワクワクするものがある。

スペックの限られたマシンでも、用途やモデルのサイズを割り切れば十分に実用的だ。ちょっとしたアイデア出しや文章の推敲など、日々の道具として手元に置いておきたい。
