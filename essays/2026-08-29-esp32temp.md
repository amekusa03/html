# ESP32-C3で温度センサーを追加

2026-8-29

## 経緯

前回、ESP32-C3にWebサーバーを設定し、照度センサーとSwitchBot Smart Homeを統合したデバイスを作った。まだポートが余っていたので、B3950 10k NTCサーミスタを繋いで温度センサーも追加してみた。

## 概要

![web](essays/2026-08-29-esp32temp.png)

- **温度計測**: `GPIO3` (ADC1_CH3) にB3950 10k NTCサーミスタと10kΩプルダウン抵抗の分圧回路を接続。B定数 (3950K) で実温度を演算。Web UIから温度オフセットを設定でき、NVSに永続保存される。
- **SwitchBot API v1.1 認証**: `mbedtls` を使いHMAC-SHA256署名を生成。NTP (`esp_netif_sntp`) でミリ秒精度のタイムスタンプを取得してAPIリクエストに使用。
- **mDNS対応**: `http://esp32-switchbot.local/` でアクセス可能。Matter の mDNS と共存する delegate hostname 方式を採用。
- **SoftAPフォールバック**: Wi-Fi未設定時は自動でAPモード (`ESP32-SwitchBot-Setup`, `192.168.4.1`) で起動。設定はNVSに永続保存。

## ピン配置

| ESP32-C3 ピン | 接続先 | 役割 |
| :--- | :--- | :--- |
| **3.3V** | CdSセルの片足 | 電源供給 |
| **GPIO1 (ADC1_CH1)** | CdSセルとプルダウン抵抗（約9.1kΩ）の接続点 | ADC照度計測入力 |
| **GPIO3 (ADC1_CH3)** | B3950サーミスタとプルダウン抵抗（10kΩ）の接続点 | ADC温度計測入力 |
| **GND** | プルダウン抵抗（約9.1kΩ）の片足 | グランド |
| **GPIO9** | タクトスイッチ（GNDへ短絡） | 3秒長押しでファクトリーリセット |
