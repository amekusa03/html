# 音の沼にハマった話 〜Ubuntuで「原音」を追いかけて〜　[前編]

正直に言うと、最初はただ「音量ボタンが効かないな」くらいの軽い気持ちだった。

うちのUbuntu機、音量調整はキーボードのショートカットで済ませていたんだけど、ふと「これって本当に自分の意図した音量になってるのか？」と疑問に思った瞬間から、沼への片道切符を買ってしまったらしい。気づけば`pactl`だの`pw-top`だのとにらめっこした。

## まずは基本、ボリューム操作コマンド

今どきのUbuntu（PulseAudio/PipeWire環境）で音量をいじるなら、`pactl`が標準的な入り口だ。

```bash
pactl set-sink-volume @DEFAULT_SINK@ +5%   # 5%上げる
pactl set-sink-volume @DEFAULT_SINK@ -5%   # 5%下げる
pactl set-sink-volume @DEFAULT_SINK@ 50%   # 50%に固定
pactl set-sink-mute @DEFAULT_SINK@ 1       # ミュート
```

古い環境や好みでALSAベースの`amixer`を使う手もある。ミュート解除は`amixer sset Master on`、音量固定は`amixer sset Master 50%`という具合。

個人的に地味に気に入っているのが`alsamixer`。端末の中に音量バーがニョキッと出てきて、矢印キーでいじれるあの画面。GUIを開くまでもない時にちょうどいい。`Esc`で抜けるのを忘れて「あれ、閉じ方どうすんだっけ」となるのはお約束。

## PipeWireの中身を覗いてみる

ここまでは前置き。本題はここから。

まず自分の環境がちゃんとPipeWireで動いているか確認する。

```bash
pactl info
```

「サーバー名: PulseAudio (on PipeWire 1.x.x)」と出れば合格。さらに`pw-top`を叩くと、今まさに流れている音声のサンプリングレートやビット数、遅延の様子がリアルタイムで見える。これがなかなか面白くて、動画を再生したり音楽を流したりしながらこの数字が動くのをぼーっと眺めてしまう時間があった。無駄と言えば無駄だけど、こういう寄り道が結局は理解を深めてくれたりする。

![pw-top](essays/2026-08-06-pipewire.png)

もっと詳しい接続状態を見たければ`wpctl status`も併せて確認しておくと安心。

## ビットパーフェクト再生という沼の底

さて、ここで気になったのが「PipeWireって音声を勝手に48kHzへ変換してるんじゃないか」という疑惑。CD音源は44.1kHzが基本なのに、それを一律48kHzにリサンプリングされたら、原音とは微妙に違う音を聴かされていることになる。

これを防ぐには、設定ファイルをユーザー環境にコピーしてやる。

```bash
mkdir -p ~/.config/pipewire/
cp /usr/share/pipewire/pipewire.conf ~/.config/pipewire/
```

そして`nano ~/.config/pipewire/pipewire.conf`で開き、以下の項目のコメントアウトを外して、自分のDACが対応するレートを並べる。

```bash
default.clock.allowed-rates = [ 44100 48000 88200 96000 192000 ]
```

編集が終わったらPipeWireを再起動。

```bash
systemctl --user restart pipewire
```

これで音源本来のサンプリングレートがそのまま出力されるようになる……はずなんだけど、正直この手の設定は「変わった気がする」くらいの体感でしかなくて、耳が良い人間じゃない自分としては、数字上の理屈で納得している部分が大きい。それでも「原音に忠実」という響きには抗えないものがある。

## リサンプリング品質を最大まで引き上げる

異なるサンプリングレートの音を同時に鳴らすとき、PipeWireは内部で補正計算をしている。この精度、初期値は4なんだけど、最大の14まで引き上げられる。

```bash
mkdir -p ~/.config/pipewire/client.conf.d/
echo "stream.properties = { resample.quality = 14 }" > ~/.config/pipewire/client.conf.d/hires.conf
```

たった1行のファイルなんだけど、地味に効いてくる系の設定だと思う。

## サラウンドをそのまま流したいなら

AVアンプにAC3やDTSといったサラウンド音声をそのまま流したい場合は、素直に`pavucontrol`を使うのが一番確実。

```bash
sudo apt install pavucontrol
pavucontrol
```

「出力デバイス」タブの「Advanced」から、対応コーデックのパススルーをON/OFFできる。ここはコマンドでゴリゴリやるより、GUIで一発の方が早い。

## CDの規格をおさらいしつつ、Rhythmboxの設定へ

そもそも音楽CDって44.1kHz/16bitという規格で、1秒間に44,100回も音を区切って、強弱を65,536段階で記録している。改めて数字で見ると、昔の技術者たちがどれだけ考え抜いてこの規格を決めたのか、ちょっと感心してしまう。この原音を劣化させずに取り込むには、さっきのPipeWire側の44100許可設定が地味に効いてくる。

RhythmboxはPipeWireの設定を自動で引き継いでくれるので、アプリ側でいじるのは主に運用面の設定だ。

**CD取り込みの音質重視設定**
「メニュー」＞「設定」＞「楽曲」タブで、優先フォーマットを`FLAC`に。ロスレス圧縮なので音質劣化なしにCD原音を維持しつつ、容量も抑えられる。

**音量の自動均一化（リプレイゲイン）**
「設定」＞「再生」タブで、リプレイゲインを「楽曲を好む」か「アルバムを好む」に設定。曲ごとの音量差にイライラしなくて済む。

**曲の繋ぎ目を滑らかに（クロスフェード）**
同じく「再生」タブでクロスフェードにチェックを入れ、2.0秒前後に。アルバムを通しで聴くタイプの人間にはありがたい機能。

## 再生できない時のお守り

MP3やAACが再生できない、という壁にぶつかったら、これを唱えておけば大体解決する。

```bash
sudo apt update
sudo apt install ubuntu-restricted-extras
```

インストール中に規約同意の画面が出てくるので、`Tab`キーで「了解/OK」に合わせて`Enter`。ここでマウスを探して右往左往するのはあるあるだと思う。
